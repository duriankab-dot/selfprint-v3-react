## 🔧 IMPLEMENTATION NOTES
### Tokens (tokens.css)
```css
:root {
  /* Evolution version colors */
  --color-version-1: #6B7280;      /* Gray - Landing/Initial */
  --color-version-2: #3B82F6;      /* Blue - Onboarding/Refined */
  --color-version-3: #8B5CF6;      /* Purple - Living/Evolved */

  /* Glow variants for visual effects */
  --color-version-1-glow: rgba(107, 114, 128, 0.4);
  --color-version-2-glow: rgba(59, 130, 246, 0.4);
  --color-version-3-glow: rgba(139, 92, 246, 0.4);

  /* Transition tokens */
  --version-transition-duration: 600ms;
  --version-transition-easing: cubic-bezier(0.4, 0, 0.2, 1);
}

/* Dark mode adjustments */
[data-mode="dark"] {
  --color-version-1: #9CA3AF;
  --color-version-2: #60A5FA;
  --color-version-3: #A78BFA;
}
```

### Usage
- EvolutionVisualization: version node colors, connectors, diff panel accents
- LivingTwin: version indicator badge, progress ring
- TwinProfile: version badge, DNA visualization accent
- IntroSummary/QuickSummary: version-aware styling
