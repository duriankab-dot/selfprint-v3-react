## 🔧 IMPLEMENTATION NOTES
### useSessionPersistence Hook
```typescript
interface SessionPersistenceState {
  authRestored: boolean;
  currentRoute: string;
  scrollPosition: { x: number; y: number };
  formDrafts: Record<string, any>;
  lastSync: number;
}
```

### Auth Restore
- เรียก Supabase `getSession()` on mount
- Hydrate AuthContext + TwinContext + LifecycleStore
- Retry logic with exponential backoff

### Route State Persistence
- `sessionStorage.setItem('sp_route', JSON.stringify({path, scroll}))`
- Restore on mount, clear on explicit logout

### Cross-tab Sync
- `new BroadcastChannel('selfprint-session')`
- Events: `auth-change`, `route-change`, `form-draft`, `twin-update`
- Deduplicationด้วย timestamp

### Form Drafts
- Auto-save ทุก 2s (debounced)
- Key: `sp_draft_${route}`
- Clear on submit success
