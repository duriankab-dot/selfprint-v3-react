## 🔧 IMPLEMENTATION NOTES

### useMemoryInsights
```typescript
interface UseMemoryInsightsReturn {
  memories: Memory[];
  search: (query: string, filters?: MemoryFilters) => Promise<Memory[]>;
  getContext: (memoryId: string) => Promise<MemoryContext>;
  loading: boolean;
  error: Error | null;
}
```
- Debounced search (300ms)
- Client-side filtering + server fallback
- Cache ด้วย React Query (5min stale)

### useEvolution
```typescript
interface UseEvolutionReturn {
  timeline: EvolutionEvent[];
  currentVersion: TwinVersion;
  getDiff: (from: TwinVersion, to: TwinVersion) => EvolutionDiff;
  triggers: EvolutionTrigger[];
  loading: boolean;
}
```
- Subscribe to TwinStore evolutionLog
- Compute diff on demand
- Trigger attribution from decision/conversation/world events
