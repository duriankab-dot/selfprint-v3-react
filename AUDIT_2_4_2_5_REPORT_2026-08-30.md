### 🔴 P0-B: `fetchUserTwin()` ยุบทั้ง Error Modes

**โค้ดปัจจุบัน** (`src/services/TwinSupabaseService.ts:17-36`):
```typescript
export async function fetchUserTwin(userId: string): Promise<Twin | null> {
  try {
    if (!userId || !supabase) return null;

    const { data, error } = await supabase
      .from('twins')
      .select('*')
      .eq('user_id', userId)
      .maybeSingle();

    if (error) {
      throw error;
    }

    return data as Twin;
  } catch (err) {
    console.error('Failed to fetch Twin:', err);
    return null;  // ← ปัญหา: ยุบทุก error เป็น null เหมือนกัน
  }
}
```

**ปัญหา:**
- Network error → `return null`
- RLS error (permission denied) → `return null`
- ไม่มีแถวจริง (Twin ยังไม่สร้าง) → `return null`
- Supabase offline → `return null`

**ไม่สามารถแยกได้:** "ไม่มีทวินจริง" vs "Error loading Twin"

**ผลกระทบ:**
- `Dashboard.tsx` ไม่รู้ว่าให้ retry หรือให้ onboarding
- `lifecycle.status` อาจ drift (กลับไป onboarding ทั้งที่เคยทำแล้ว)
- UX: ผู้ใช้ไม่รู้ว่ากำลังโหลด ล้ม หรือจริงๆ ไม่มีทวิน

**ต้องแก้:**
```typescript
export async function fetchUserTwin(userId: string): Promise<Twin | null | 'error'> {
  try {
    if (!userId || !supabase) return 'error';
    
    const { data, error } = await supabase.from('twins').select('*')...
    
    if (error) {
      // Specific error handling
      if (error.code === 'PGRST116') return null; // 0 rows (Twin not yet created)
      if (error.code === '42P01') return 'error'; // Table doesn't exist
      if (error.message.includes('permission')) return 'error'; // RLS
      return 'error'; // Default: network or other error
    }
    
    return data as Twin;
  } catch (err) {
    return 'error';
  }
}
```

### 🔶 P0-A: Twin Birth ไม่ Atomic

**ตรวจสอบ:**
- Twin creation ใน backend (ที่ไหนก็ได้) ใช้ pattern:
  ```typescript
  // Create Twin
  const twin = await createTwin(...);
  
  // Create SICE
  await createSICE(...);  // Promise.all or individual?
  
  // Create world_preferences
  await createWorldPrefs(...);
  
  // Return success: true
  ```

**หากเพียงข้อใด fail:**
- Twin สร้างสำเร็จ แต่ SICE/world_prefs fail
- Frontend ได้ `success: true` ไปเรื่อย
- Twin มี incomplete data

**ต้องแก้:**
```typescript
try {
  const results = await Promise.all([
    createTwin(...),
    createSICE(...),
    createWorldPrefs(...)
  ]);
  
  if (results.some(r => !r.success)) {
    throw new Error('Twin birth incomplete');
  }
  
  return { success: true };
} catch (err) {
  // Rollback or error state
  return { success: false, error: '...' };
}
```
