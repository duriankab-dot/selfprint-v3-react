## Section 0: Executive Direction & Vision

### 0.1 North Star Statement

**SELFPRINT IS NOT AN AI THAT TALKS TO YOU.**

**IT IS AN AI THAT LEARNS TO UNDERSTAND YOU.**

Selfprint ต้องพัฒนาจาก:
- ❌ เว็บที่มี AI วิเคราะห์ผู้ใช้
- ❌ Chatbot + Personality Test + Journal รวมกัน

ไปสู่:
- ✅ **Living Personal Intelligence Environment**

ผู้ใช้ต้องรู้สึกว่า:
> "Selfprint กำลังเรียนรู้และเข้าใจฉันมากขึ้นเรื่อย ๆ"

### 0.2 Core Experience Loop

ทุก UX ต้องสนับสนุนวงจรนี้:

```
UNDERSTAND (AI เข้าใจฉัน)
    ↓
REMEMBER (AI จำสิ่งสำคัญ)
    ↓
REFLECT (ฉันสะท้อนตัวเอง)
    ↓
DETECT (AI พบ Pattern / Change)
    ↓
ADAPT (ระบบปรับประสบการณ์)
    ↓
GUIDE (AI ให้คำแนะนำเฉพาะบุคคล)
    ↓
EVOLVE (Twin + Personal Model เติบโต)
    ↺ (วนซ้ำในระดับที่ลึกขึ้น)
```

### 0.3 Product Philosophy

**หลักสำคัญ:**

> Do not optimize for "more AI". Optimize for "more correctly personal".

และ:

> AI may personalize the experience. The user remains in control.

Selfprint ไม่แข่งขันด้วยจำนวนฟีเจอร์ แต่แข่งด้วย **ความรู้สึกว่า AI เข้าใจผู้ใช้อย่างถูกต้องและต่อเนื่อง**

## Section 1: Living AI Twin & Personal Intelligence

### 1.1 AI Twin — หัวใจของ Selfprint

AI Twin **ไม่ใช่:**
- Avatar ธรรมดา
- Chatbot
- AI Assistant
- รูปคน

**แต่เป็น:** Visual representation ของ Personal Intelligence Model ที่มีชีวิตในเชิงประสบการณ์

Twin ต้องสามารถ:
- เข้าใจสิ่งที่ผู้ใช้เคยเล่า
- เห็นรูปแบบระยะยาว
- เชื่อม Journey, Reflection, Goals
- จำข้อมูลที่ได้รับอนุญาตให้จำ
- ชวนผู้ใช้สะท้อนตัวเอง
- ช่วยผู้ใช้ตัดสินใจ
- ปรับประสบการณ์บน Dashboard
- เติบโตไปพร้อมกับ Personal Model

### 1.2 Twin Evolution States

Twin มีสถานะที่สะท้อนการพัฒนา:

- **Awakening** — เพิ่งเกิด
- **Aware** — เริ่มรู้จักผู้ใช้
- **Connected** — เชื่อมต่อเข้าใจเพิ่มขึ้น
- **Reflective** — เห็นรูปแบบ
- **Insightful** — ให้ข้อมูลเชิงลึก
- **Aligned** — ตรงกับผู้ใช้อย่างเต็มที่

ระดับเหล่านี้ **ไม่ใช่ gamification อย่างเดียว** แต่สะท้อนความลึกของ Personal Model และการ engagement ที่เกิดขึ้นจริง

### 1.3 Twin Synthesis Experience — WOW Moment

ตอนสร้าง Twin ต้องเป็น **Signature Experience**

**Visual Direction:**
- ร่างกายมนุษย์แบบ futuristic / holographic / cosmic
- ระหว่าง synthesis:
  - ร่างกายกำลังก่อตัว
  - หมุนช้า ๆ
  - มี energy / particles
  - ตัวเลขและ data stream เคลื่อนผ่าน
  - neural / intelligence engine effect
  - cosmic blue-purple lighting
  - data convergence → final stabilization

**ความรู้สึกที่ต้องการ:**
> เหมือนกำลังสร้าง Digital Self จากข้อมูลของผู้ใช้ (ไม่ใช่ loading screen ธรรมดา)

### 1.4 Processing States ที่ทำให้ผู้ใช้เข้าใจ

ห้ามใช้ "Loading..." ธรรมดา

Twin ต้องเป็นส่วนหนึ่งของ process:

| State | ความหมาย |
|-------|---------|
| **ANALYZING** | กำลังทำความเข้าใจข้อมูล |
| **SYNTHESIZING** | กำลังเชื่อมโยงรูปแบบ |
| **CALIBRATING** | กำลังปรับ Personal Model |
| **AWAKENING** | Twin กำลังถูกสร้าง |
| **READY** | Twin พร้อมทำความรู้จักคุณ |

## Section 2: Personal Intelligence System

### 2.1 Native Personal Intelligence Engine

**P0 Priority:**

AI ต้องฉลาดตั้งแต่ First Session

ผู้ใช้ต้องได้รับความรู้สึกว่า: **"มันรู้จักฉันจริง"** ตั้งแต่ครั้งแรก

**First-session Pipeline:**

```
User Input
    ↓
Validation
    ↓
Personal Context
    ↓
Multi-source Synthesis
    ↓
Pattern Analysis
    ↓
Confidence Assessment
    ↓
Relevance Ranking
    ↓
First Insight (ต้องมีความลึก ไม่ generic)
    ↓
Twin Birth
```

### 2.2 Personal Model — ข้อมูลที่ AI ใช้

Personal Intelligence รวบรวมจาก:

```
HIGH CONFIDENCE SIGNALS
├── User-Reported Data (สิ่งที่ผู้ใช้บอกโดยตรง)
├── Behavior (พฤติกรรมจริง)
├── Long-term Patterns (รูปแบบระยะยาว)
├── Reflection (การสะท้อนตัวเอง)
├── Goals (เป้าหมาย)
├── Values (คุณค่า)
└── Journal (บันทึก)
    ↓
EXPLORATORY SIGNALS (ผ่านการยืนยันของผู้ใช้)
├── Fingerprint (ลายนิ้วมือ)
├── Palm (ลายมือ)
├── Hexagram (เซียมซี)
└── Symbolic Systems (ระบบสัญลักษณ์)
```

### 2.3 Data Hierarchy — ลำดับความสำคัญ

```
1. สูงสุด: สิ่งที่ผู้ใช้บอก + พฤติกรรมจริง
2. สูง: รูปแบบระยะยาว + Reflection + Goals + Values
3. กลาง: Journey + Analysis + Personal Context
4. ต่ำ: Exploratory Signals (ต้องผ่านการยืนยันผู้ใช้)
```

**กฎสำคัญ:**
- ถ้าผล Exploration ขัดกับพฤติกรรมจริง → ข้อมูลจริงของผู้ใช้ต้องชนะ
- ห้ามให้ Fingerprint/Palm/Hexagram มีน้ำหนักเท่า Behavioral Data

### 2.4 AI Evidence & Confidence

AI ห้ามทำเป็นรู้ทุกอย่าง

ทุก Insight สำคัญต้องมี:
- **Evidence** — เหตุฐานอะไรบ้าง
- **Recency** — นานมากแล้วมั้ย
- **Confidence** — มั่นใจขนาดไหน
- **Relevance** — เกี่ยวข้องหรือไม่

**AI ต้องแยก:**

| ประเภท | ความหมาย | ตัวอย่าง |
|--------|---------|---------|
| **KNOW** | สิ่งที่ผู้ใช้บอกโดยตรง | "คุณบอกว่าชอบการเขียน" |
| **INFER** | สิ่งที่ AI สรุปจากหลักฐาน | "ดูเหมือนคุณมีโอกาสว่างวันจันทร์" |
| **UNKNOWN** | สิ่งที่ AI ยังไม่รู้ | "ฉันยังไม่รู้เกี่ยวกับ..." |

**หลักเหนือสิ่งสิ่งอื่น:**
> Never pretend to know what the system does not know.

### 2.5 AI Feedback Loop — Calibration

หลัง Insight สำคัญ ให้ผู้ใช้ตอบ:

```
AI Insight
    ↓
User Feedback (Very true / Somewhat / Not sure / Not me)
    ↓
Model Calibration
    ↓
Better Personal Context
    ↓
Better Twin
```

นี่เป็น **Core Learning Loop** ของ Selfprint

### 2.6 Deep Personal Analysis

นำจุดแข็งจาก Astrovera มาต่อยอด แต่สร้างใหม่เป็น Native Intelligence ของ Selfprint

**ไม่ใช่:** copy Astrovera UI หรือ architecture เดิม

**Full Personal Analysis ควรประกอบด้วย:**

1. **ภาพรวมตัวตน** — ผู้ใช้เป็นอย่างไร
2. **รูปแบบพฤติกรรม** — สิ่งที่เกิดซ้ำ
3. **จุดแข็ง** — สิ่งที่กำลังทำงานได้ดี
4. **Blind Spots** — สิ่งที่อาจไม่เห็นด้วยตัวเอง
5. **แนวโน้ม** — สิ่งที่กำลังเปลี่ยน
6. **Journey** — กำลังอยู่ตรงไหนของการเติบโต
7. **สิ่งที่ควรให้ความสนใจ** — ประเด็นสำคัญในปัจจุบัน
8. **Personal Guidance** — คำแนะนำเฉพาะบุคคล
9. **Next Step** — สิ่งที่ควรทดลองหรือทำต่อ

### 2.7 Behavioral Pattern Intelligence

Selfprint ต้องตอบได้ว่า:

- **What keeps repeating?** — สิ่งที่เกิดซ้ำ
- **What is changing?** — สิ่งที่เปลี่ยน
- **What is emerging?** — สิ่งที่กำลังเกิดขึ้น

**ตัวอย่าง:**
> "ช่วงที่ผ่านมา คุณเริ่มเปลี่ยนจากการวิเคราะห์ทางเลือกจำนวนมาก ไปสู่การทดลองจริงมากขึ้น"

นี่มีค่ากว่า Personality Label เช่น "คุณเป็นคนคิดมาก" เพราะ **Selfprint ต้องติดตามการ evolution ของมนุษย์**

### 2.8 Memory System

AI ต้องมี **Persistent Personal Memory** ที่ผู้ใช้ควบคุม

**ประเภท Memory:**

- **Small Wins** — ความสำเร็จเล็ก ๆ
- **Important Moments** — เหตุการณ์สำคัญ
- **New Discoveries** — สิ่งที่ผู้ใช้ค้นพบเกี่ยวกับตัวเอง
- **Personal Memories** — ข้อมูลที่ผู้ใช้ต้องการให้ Twin จำ

**ผู้ใช้ต้องสามารถ:**
- ดู Memory
- แก้ไข Memory
- ลบ Memory
- Clear AI Memory

## Section 4: Experience Personalization & Design

### 4.1 Experience Intelligence Engine

Selfprint ไม่ควรเพียง "เข้าใจผู้ใช้" แต่ต้อง **ปรับประสบการณ์ให้เหมาะกับผู้ใช้**

```
Personal Context
    +
Current Mood / Hub
    +
Emotional Signal
    +
Journey
    +
Activity
    +
Time
    ↓
Experience Engine
    ↓
Selects:
├── Hub emphasis
├── Theme
├── Twin state
├── Motion
├── Audio
├── Dashboard priority
└── Notification type
```

### 4.2 Theme System — 66–72 Themes

Selfprint มี Theme Background ประมาณ 66–72 แบบ เกิดจาก: **Emotion × Hub**

**กฎสำคัญ:**
- AI **ไม่ควร generate theme ใหม่** เอง
- แต่เลือก Theme จาก library ที่มีอยู่แล้ว

```
Context
    ↓
Emotion + Hub
    ↓
Theme Resolver
    ↓
66–72 Existing Themes
```

Theme สามารถควบคุม:
- Background
- Gradient
- Lighting
- Particle density
- Twin glow
- Motion
- Atmosphere

### 4.3 Emotion Engine — Soft Signals

AI สามารถใช้ emotional signals เป็น soft signals:

```
Calm:       0.62
Reflective: 0.76
Uncertain:  0.81
Excited:    0.21
```

**สำคัญ:** ไม่ควรวินิจฉัยอารมณ์หรือสุขภาพจิต

**ใช้เพื่อ:** Experience Personalization

**ตัวอย่าง:**

| Experience | Visual | Audio | Mood |
|------------|--------|-------|------|
| Deep Reflection | Dark cosmic | Ambient piano | Slow motion |
| Discovery | Purple / cyan | Exploration music | Active particles |
| Achievement | Gold / bright | Cinematic sound | Twin evolution |

### 4.4 User Preference มีสิทธิ์เหนือ AI

**Hierarchy:**

```
User Preference (สิทธิสูงสุด)
    ↓
Accessibility / Safety
    ↓
Product Rules
    ↓
Design System
    ↓
Experience Context
    ↓
AI Personalization (สิทธิต่ำสุด)
```

**ตัวอย่าง:** ถ้า user เลือก "Always Dark Theme" AI ห้ามเปลี่ยนเองเพราะตีความอารมณ์

### 4.5 Voice Twin

ต้องรองรับ:

| Mode | Flow |
|------|------|
| **Text Mode** | พิมพ์ → AI → Text |
| **Voice Mode** | พูด → Speech-to-Text → AI → Voice |

ผู้ใช้ควรสามารถ: **"Talk to your Twin"**

ต้องมี:
- Start / Stop
- Interrupt
- Voice preference
- Text fallback
- Accessibility controls

### 4.6 Adaptive Voice

เสียงควรปรับตาม Experience Mood:

| Mood | ลักษณะ |
|------|--------|
| Calm | นุ่ม / ช้าลง |
| Focus | กระชับ / ชัด |
| Reflection | มีจังหวะเว้น |
| Celebration | energetic ขึ้นเล็กน้อย |

**สำคัญ:** ไม่ควรแสดงอารมณ์เกินจริงจนดูเป็นนักแสดง

### 4.7 Adaptive Background Music

เพิ่ม: **Adaptive Ambient Layer**

| Experience | Sound |
|------------|-------|
| Reflection | Ambient / Piano |
| Focus | Minimal Pulse |
| Discovery | Cosmic Ambient |
| Deep Reflection | Sparse Ambient |
| Celebration | Cinematic Uplift |

**ต้องใช้ Audio Ducking:**
- เมื่อ Twin พูด: Music ↓
- เมื่อ Twin หยุด: Music ↑

### 4.8 Audio Permission

ไม่ควร autoplay เสียงทันที

ให้ user เปิด: `Enable immersive experience`

จากนั้นจำ preference

**มี options:**
- Sound ON/OFF
- Music ON/OFF
- Voice ON/OFF
- Volume
- Reduce Motion

## Section 6: Development Rules & Discipline

### 6.1 Core Principle — ตรวจระบบเดิมก่อนทุกครั้ง

**ห้ามสร้าง Feature ซ้ำกับระบบเดิม**

ก่อนสร้าง Component / Page / Feature ใหม่ ให้ตรวจสอบว่าระบบปัจจุบันมีสิ่งต่อไปนี้อยู่แล้วหรือไม่:

- Component
- API
- Database
- AI Prompt
- Voice System
- Audio System
- User Profile
- Assessment
- Journal
- Reflection
- Journey
- Archetype
- AI Chat
- Personal Data
- Dashboard
- Authentication
- PWA Infrastructure

ถ้ามีอยู่แล้ว:
✅ นำของเดิมมาปรับ / เชื่อม / ขยายความสามารถ
❌ ห้ามสร้างระบบใหม่ที่ทำงานซ้ำกัน

### 6.2 Audit ระบบเดิม ก่อนเขียน Code

สร้าง Audit จากระบบปัจจุบัน:

```
EXISTING
├── Pages
├── Components
├── APIs
├── Database
├── AI
├── Prompts
├── Voice
├── Audio
├── User Profile
├── Journal
├── Reflection
├── Journey
├── Assessment
├── Archetype
├── AI Chat
└── Authentication

แล้วแบ่งเป็น:

KEEP
└── ของเดิมดี → ใช้ต่อ

MODIFY
└── ของเดิมมี → ปรับ

EXTEND
└── ของเดิมมี → เพิ่มความสามารถ

REPLACE
└── ของเดิมไม่เหมาะ → ค่อยพิจารณา

NEW
└── สร้างเฉพาะสิ่งที่ยังไม่มีจริง ๆ
```

### 6.3 Language Policy — ภาษาไทยเป็นหลัก

UI ใช้ภาษาไทยเป็นหลัก ต้องใช้คำที่คนทั่วไปเข้าใจ

- Technical documentation

- สั้น
- เข้าใจง่าย
- เป็นธรรมชาติ

- ไม่ยัดศัพท์เทคนิค
- ไม่พูดเหมือนระบบราชการ

AI ต้องรู้ว่าเมื่อไรควร:
- อธิบาย
- ถาม
- หยุด
- แนะนำ
- ให้ผู้ใช้เลือก

โดยเฉพาะข้อมูลจาก:
- Fingerprint
- Palm
- Hexagram
- Astrology
- Symbolic systems
- Personality exploration

ต้อง **ไม่พูดเป็นข้อเท็จจริงเด็ดขาดเกินหลักฐาน**

- "อาจสะท้อน..."

- "นี่เป็นมุมมองหนึ่ง..."
- "ใช้เพื่อการสำรวจตัวเอง..."

**ตัวอย่าง:**

- ถ้าช่วงนี้พูดเรื่อง Relationship มาก → Relationship

**สำคัญ:** ไม่ควรเปลี่ยน Navigation หลักจนผู้ใช้หลงทาง

ให้เปลี่ยน: Priority / Emphasis แทน

### 6.7 Smart Push Notification

Push ต้องเป็น **Contextual Intelligence Notification**

ไม่ส่งทุกวันแบบ Spam

**ประเภท:**

| Type | Message |
|------|---------|
| Reflection | Your Twin has a question for you. |
| Pattern | Your Twin noticed something. |
| Journey | Your Journey may be changing. |
| Milestone | Your Twin evolved. |

**ระบบเรียนรู้:**
- เวลาใช้งาน
- response rate
- notification engagement
- notification ที่ถูก ignore
- preferred time

แล้วปรับ: **Timing + Frequency + Type** อัตโนมัติ

### 6.8 Contextual Popup — ไม่รบกวน

Popup ใช้เฉพาะ:
- Discovery (แนะนำ feature ที่เกี่ยวข้อง)
- Pattern (พบ pattern ใหม่)
- Milestone (เกิด evolution)
- Re-engagement (ผู้ใช้กลับมาหลังหายไป)

**หลัก:** Contextual, not interruptive

ห้ามใช้ Popup เพื่อเร่ง Conversion ทุกครั้ง

### 6.9 สิ่งที่ Dev ห้ามทำ

❌ สร้าง Feature ซ้ำกับระบบเดิม  
❌ สร้าง Journal ใหม่ถ้ามีอยู่แล้ว  
❌ สร้าง Voice System ใหม่ถ้าของเดิมใช้ได้  
❌ สร้าง AI Chat ใหม่โดยไม่ตรวจระบบเดิม  
❌ ทำ Today เป็น Static Dashboard  
❌ เพิ่ม Bottom Navigation เพื่อรองรับ Feature ใหม่  
❌ ใช้ศัพท์ Technical เยอะใน UI  
❌ ให้ Fingerprint/Palm/Hexagram มีน้ำหนักเท่า Behavioral Data  
❌ ให้ AI อ้างผล Exploratory Signal เป็นข้อเท็จจริง  
❌ ให้ AI สร้าง UI แบบไร้ข้อจำกัด  
❌ บังคับผู้ใช้เปิดเสียง  
❌ บังคับตั้งค่าจำนวนมากตอน Onboarding  
❌ Spam Push Notification  
❌ ใช้ Popup มากเกินไป

❌ ล็อก Basic Identity หลัง Paywall

## Section 11: Final Directive to AI Dev

### Do not build Selfprint as a collection of features.

**Build it as a Living Personal Intelligence Experience.**

#### ต้องทำ:

✅ Preserve and reuse all existing systems.

✅ Use the **5 Navigation architecture**:
```
วันนี้ | สำรวจ | กิจกรรม | AI ฝาแฝด | ฉัน
```

✅ Make **"วันนี้ของฉัน"** dynamic.

✅ Use **Section Library + Activity Library + AI Orchestrator** rather than allowing AI to invent UI.

✅ Treat **Explore** as discovery lens.

✅ Treat **Activities** as active engagement and structured input.

✅ Treat **Twin** as the relationship layer.

✅ Treat **Journal / Reflection / Memory / Pattern / Journey** as interconnected intelligence systems, not isolated features.

✅ Treat Fingerprint / Palm / Hexagram as exploratory lenses, not absolute truth.

✅ Let user feedback calibrate exploratory signals.

✅ Give Free users a real Selfprint experience.

✅ Monetize **Depth, Intelligence, Guidance and Twin Evolution**, not identity.

✅ Use contextual monetization rather than intrusive paywalls.

✅ Optimize for long-term accumulated value.

✅ Every interaction should have the potential to make Selfprint understand the user better.

ทุก Feature ใหม่ต้องตอบให้ได้ว่า:
