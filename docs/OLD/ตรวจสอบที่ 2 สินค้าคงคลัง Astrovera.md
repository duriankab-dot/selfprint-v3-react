## ส่วนที่ง: โครงสร้างโมดูลความรู้ (แม่แบบ)

แต่ละโมดูล (เช่น `psychology/`) ประกอบด้วย:

```
psychology/
├── system.js         # พรอมต์ระบบ (โมดูลนี้ทำอะไร)
├── instruction.js    # คำแนะนำโดยละเอียดสำหรับ AI
├── schema.js         # สคีมา TypeScript อินพุต/เอาท์พุต
├── examples.js       # คู่ตัวอย่างอินพุต/เอาท์พุท
├── version.js        # ติดตามเวอร์ชัน
└── index.js          # ส่งออก buildPrompt(), SCHEMA, validate()
```

**ตัวอย่างการใช้:**
```javascript
import * as Psychology from 'brain/knowledge/psychology/index.js'
const prompt = Psychology.buildPrompt({ exampleCount: 2 })
const result = await callClaude(prompt, input)
const validated = Psychology.validate(result)
```

**รูปแบบความสามารถในการใช้ซ้ำ:** ✅ สามารถใช้ซ้ำได้มากมาย การแก้ไขน้อยที่สุดที่จำเป็น

## สรุป: Astrovera นำมาสู่ Selfprint

### ต้องมี (P0)
1. โมดูลความรู้จิตวิทยา (การวิเคราะห์แบบอาร์คิไทป์การตัดสินใจ)
2. เกตเวย์ + ผู้ประสานงาน (การกำหนดเส้นทางและการสังเคราะห์หลายโดเมน)
3. การสร้างบริบทหน่วยความจำ (บริบทที่ซับซ้อน)

### ควรมี (P1)
4. ตัวแทนโค้ช + ตัวแทนข้อมูลเชิงลึก (แนวทางการตัดสินใจ)
5. โมดูลตัวเลข (การปรับปรุง Life Path)

### ดี-ที่-มี (P2+)
6. โมดูล astrology ทางเลือก (มุมมองจักรวาล)
7. ระบบบุคลิกลักษณ์ (เสียง)
8. การให้คะแนนความเชื่อมั่น (การสังเคราะห์หลายแหล่ง)

### ไม่จำเป็น
- คอมโพเนนต์ UI Astra/Nova
- หน้าต่อพิมพ์ Astrovera ทั้งหมด
- อาร์คิเทคเจอร์ผู้ปฏิบัติงาน Astrovera (ออกแบบใหม่สำหรับ Vercel/Supabase)
- โมดูลกรุ๊ปเลือด (เฉพาะเจาะจงเกินไป)
