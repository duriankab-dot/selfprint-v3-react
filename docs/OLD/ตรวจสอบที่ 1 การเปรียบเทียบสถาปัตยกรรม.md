**วันที่:** 9 สิงหาคม 2026 | **สถานะ:** แบบร่าง - รอการตรวจสอบ  
**ขอบเขต:** การแยกคุณลักษณะและการวางแผนการรวมระบบ

## สรุปผู้บริหาร

การตรวจสอบนี้ประเมินความเป็นไปได้ของการรวม Astrovera ฉลาดแบ็กเอนด์เข้า Selfprint ผ่าน **สถาปัตยกรรมเกตเวย์แยกต่างหาก**

### การตัดสินใจ
✅ **ดำเนินการตามตัวเลือก A (การรวมระบบแยกต่างหาก)**
- Astrovera ให้เลเยอร์แบ็กเอนด์ฉลาด
- Selfprint รักษาเอกราชของหน้าต่อพิมพ์/UX/แบรนด์
- เกตเวย์ abstractทั้งหมดรายละเอียด Astrovera
- ไม่มีการรั่วไหล UI/นำทางจาก Astrovera ไป Selfprint

## สถาปัตยกรรมการรวมระบบ (เสนอ)

```
┌────────────────────────────────────────────────────────┐
│  หน้าต่อพิมพ์ Selfprint (React)                        │
│  - UI/UX (แบรนด์ Selfprint เท่านั้น)                 │
│  - ตัวเลือกอารมณ์                                    │
│  - อินเตอร์เฟซวารสาร                                 │
│  - การแสดงโปรไฟล์                                   │
│  - นำทาง (การไหล Selfprint)                         │
└────────────────────────────────────────────────────────┘
                         ↓
┌────────────────────────────────────────────────────────┐
│  เลเยอร์อแดปเตอร์ฉลาด (ใหม่)                          │
│  - แปลง Selfprint → Astrovera format                │
│  - แปลง Astrovera → Selfprint format                │
│  - ไม่มีตรรกะ UI                                    │
│  - ตำแหน่ง: src/lib/astrovera-adapter.ts            │
└────────────────────────────────────────────────────────┘
                         ↓
┌────────────────────────────────────────────────────────┐
│  บริการฉลาด (ใหม่)                                    │
│  - Supabase Edge Function หรือ API ภายใน            │
│  - เก็บข้อมูลประจำตัว Astrovera                      │
│  - การจัดการข้อผิดพลาดและการสำรอง                   │
│  - ตำแหน่ง: supabase/functions/intelligence/         │
└────────────────────────────────────────────────────────┘
                         ↓
┌────────────────────────────────────────────────────────┐
│  เกตเวย์สมอง Astrovera (ที่มีอยู่)                   │
│  - การวิเคราะห์จิตวิทยา                             │
│  - การตรวจจับรูปแบบ                                 │
│  - การสนับสนุนการตัดสินใจ                           │
│  - การจัดการหน่วยความจำ                             │
│  - เรียก: API Anthropic + Workers                  │
└────────────────────────────────────────────────────────┘
```

**หลักการสำคัญ:**
1. **การแยกส่วน:** หน้าต่อพิมพ์ Selfprint ไม่เคยนำเข้าโค้ด Astrovera
2. **Abstraction:** รายละเอียด Astrovera ทั้งหมดซ่อนไว้เบื้องหลัง API ที่รวมกัน
3. **เอกราช:** Selfprint ทำงานแม้ว่า Astrovera จะไม่พร้อม (ทำงานสำรอง)
4. **ประเภท Clean:** สัญญา TypeScript กำหนดรูปร่างข้อมูลที่แน่นอน
5. **ความปลอดภัย:** คีย์ API Astrovera อยู่ในตัวแปรสภาพแวดล้อมของ Edge Function เท่านั้น
6. **ความสอดคล้องของ UX:** ศูนย์ UI/กำหนดรูปแบบ/นำทางจาก Astrovera หลุด

## สิ่งที่ Astrovera มอบให้กับ Selfprint

### ความสามารถทางฉลาดที่ได้มา
| ความสามารถ | Selfprint ปัจจุบัน | พร้อมกับ Astrovera | มูลค่า |
|-----------|---|---|---|
| **การวิเคราะห์บุคลิกลักษณ์** | พื้นฐาน (Life Path) | ขั้นสูง (จิตวิทยา + แบบอาร์คิไทป์) | สูง |
| **การตรวจจับรูปแบบ** | ไม่มี | ประเมิน + รูปแบบวารสาร | สูง |
| **การให้คะแนนความเชื่อมั่น** | ไม่มี | การสังเคราะห์หลายแหล่ง | สูง |
| **บริบทหน่วยความจำ** | ไม่มี | การสร้างบริบทที่ซับซ้อน | สูง |
| **การสนับสนุนการตัดสินใจ** | ไม่มี | ตัวแทนโค้ช + ตัวแทนคำแนะนำ | ปานกลาง |
| **ข้อมูลเชิงลึกในหลายโดเมน** | ไม่มี | ตัวเลข, จักรราศี, ฯลฯ (ทางเลือก) | ปานกลาง |
| **การสร้างนราการ** | ไม่มี | แนวทางบุคลิกสรรพนาม | ปานกลาง |

- อินเตอร์เฟซวารสาร
- การติดตามอารมณ์
- แบรนด์ & ตัวตน

## การแมป: จุดการรวมระบบ

### การไหลประเมิน
```
การเลือกอารมณ์ → บทสนทนา Nova → วันเกิด
         ↓
[ไหล Selfprint ที่มีอยู่]
         ↓
คำถามปรับแต่ง (คำถาม 4 ข้อ)
         ↓
[จุดการรวมระบบที่ 1]
โทร: โมดูล Astrovera จิตวิทยา
อินพุต: คำตอบปรับแต่ง + อารมณ์ + วันเกิด
เอาท์พุต: แผนพิมพ์บุคลิกลักษณ์ที่ปรับปรุง
         ↓
การแสดงแผนพิมพ์
การแสดงการวิเคราะห์เต็มรูปแบบ
         ↓
บ้าน/แดชบอร์ด
```

### การใช้งานอย่างต่อเนื่อง
```
การตรวจสอบรายวัน → อารมณ์ + บริบท
         ↓
[จุดการรวมระบบที่ 2]
โทร: การตรวจจับรูปแบบ Astrovera
อินพุต: อารมณ์วันนี้ + รายการวารสาร + ประวัติ
เอาท์พุต: ข้อมูลเชิงลึกรูปแบบ + คำแนะนำ
         ↓
การแสดงวารสาร + คำแนะนำ
```

### การสนับสนุนการตัดสินใจ (อนาคต)
```
ผู้ใช้ถาม: "ฉันควรลาออกจากงานของฉันหรือไม่?"
         ↓
[จุดการรวมระบบที่ 3]
โทร: ตัวแทนการตัดสินใจ Astrovera
อินพุต: คำถาม + บุคลิกลักษณ์ + บริบท
เอาท์พุต: คำแนะนำ + การให้เหตุผล
         ↓
บัตรโค้ช / ป๊อปอัพแนวทาง
```

## สิ่งที่ไม่ได้รวมระบบ

### คอมโพเนนต์ Astrovera (ยกเว้นอย่างชัดเจน)
- ❌ คอมโพเนนต์อวตาร Astra/Nova
- ❌ โครงสร้างนำทาง Astrovera
- ❌ แบรนด์/สี Astrovera
- ❌ เค้าโครงหน้า Astrovera
- ❌ โครงสร้างแบบฟอร์ม Astrovera
- ❌ หน้าต่อพิมพ์ทั้งหมด Astrovera

### ทำไม?
Selfprint มี UX MEMO V4 ที่สวยงาม การผสมระบบ UX สร้าง:
- ความไม่สอดคล้องของภาพ
- นำทางที่ขัดแย้งกัน
- การเดินทางของผู้ใช้ที่สับสน
- การทำให้แบรนด์ลดลง
- หนี้ทางเทคนิค
