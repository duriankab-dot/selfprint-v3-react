- **Home Dashboard:** section "Your AI Twin" ใน `/dashboard` (`AITwinSection.tsx`) ดึง blueprint ที่บันทึกไว้จริงมาแสดง มี state ครบ (ยังไม่ login / ยังไม่มีข้อมูล / error)
- **Share/Referral:** `/api/share` (POST สร้าง code, GET อ่าน preview) เขียนอ่านจาก `selfprint.share_links` จริง ปุ่ม Share อยู่ใน AITwinSection แล้ว (เดิม `ShareButton` เป็น orphan component ไม่ได้ mount ที่ไหนเลย) — **แก้บั๊กเพิ่มรอบนี้:** route `/share/:id` เดิมไม่ตรงกับ `Share.tsx` ที่อ่าน `useParams` เป็น `code` ทำให้ลิงก์แชร์ใช้งานไม่ได้เลยตั้งแต่สร้างฟีเจอร์มา ตอนนี้แก้เป็น `/share/:code` แล้ว **ยังไม่เคยทดสอบจริงปลายทางถึงปลายทาง** ต้องลองสร้างลิงก์แล้วเปิดดู
- **ภาษา:** แปล UI ทั้งเว็บเป็นภาษาไทยครบทุกหน้า/component ที่ user-facing แล้ว (รอบนี้)

- **Prototype Core:** archetype 1 ใน 12 (Hero, Lover, Jester, Everyman, Explorer, Caregiver, Sage, Ruler, Innocent, Magician, Creator, Outlaw) map มาจาก Life Path Number แบบ deterministic (`getPrototypeCore` ใน `astrology.ts`) — มาจากแผนเก่า `SELFPRINT_COMPLETE_ROADMAP_TH.md` ที่ user ขอให้รวมเข้ากับระบบ blueprint ปัจจุบัน โดยเปลี่ยนชื่อจาก "Archetype" เป็น "Prototype Core" ตามที่ user สั่ง แสดงผลใน InitialBlueprint, FullAnalysis, AITwinSection และอยู่ใน export text ด้วย — maturity score ใช้ `accuracy_level` เดิม ไม่ได้สร้าง field ใหม่

## 5. กติกาที่ต้องจำ

- ถามก่อนถ้าไม่ชัด ห้ามเดา / ทำเท่าที่ขอ ไม่เกิน scope / แก้เฉพาะจุด / verify ก่อนบอกว่าเสร็จ
