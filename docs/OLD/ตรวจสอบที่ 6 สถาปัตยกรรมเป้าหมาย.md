## คุณลักษณะหลัก

### UI Selfprint (ไม่เปลี่ยนแปลง)
- ลงจอด MEMO V2
- การเข้าใช้งาน MEMO V4
- ตัวเลือกอารมณ์
- อินเตอร์เฟซวารสาร
- นำทาง Selfprint

### เลเยอร์อแดปเตอร์ (ใหม่)
- แปลง Selfprint → Astrovera
- แปลง Astrovera → Selfprint
- 100% ปก TypeScript
- ศูนย์ UI logic

### Edge Function (ใหม่)
- Supabase Functions
- อ่าน ASTROVERA_API_KEY
- เรียก Astrovera Brain
- แคชและทำงานสำรอง

### ประวัติ Supabase (ใหม่)
- analysis_history
- pattern_insights
- session_logs
