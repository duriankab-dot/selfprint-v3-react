## บท 01 — Welcome to Selfprint

### Selfprint คืออะไร

Selfprint คือ **Living Personal Intelligence Platform** — แพลตฟอร์มที่ใช้ AI สร้าง "เวอร์ชันดิจิทัลของคุณ" ที่เรียกว่า **Nova AI Twin**

Twin นี้ไม่ใช่ chatbot ทั่วไป มันเรียนรู้จากคุณสะสมตลอดเวลา จำสิ่งที่คุณบอก ตรวจจับรูปแบบพฤติกรรมของคุณ และนำเสนอ Insight ที่ลึกขึ้นเรื่อยๆ ตามเวลา

### Selfprint ช่วยอะไรคุณ

- **เข้าใจตัวเอง** — รู้ว่าตัวเองมีรูปแบบอะไร, จุดแข็งอะไร, จุดตาบอดอะไร
- **ตัดสินใจได้ดีขึ้น** — Twin วิเคราะห์บริบทและช่วยคุณคิดทะลุปัญหา
- **เติบโตตามเวลา** — เห็นพัฒนาการของตัวเองผ่าน Journey และ Patterns
- **มีพื้นที่คิด** — คุยกับ Twin ที่ฟังและเข้าใจ ไม่ตัดสิน

### แนวคิดหลัก: Understand → Remember → Reflect → Detect → Adapt → Guide → Evolve

Selfprint ทำงานตามวัฏจักรนี้:

1. **Understand** — AI เรียนรู้ว่าคุณเป็นใครจากการสนทนาและข้อมูลที่คุณให้
2. **Remember** — Twin จำทุกอย่างที่สำคัญ ข้ามวัน ข้ามเดือน
3. **Reflect** — คุณสะท้อนตัวเองผ่านการเขียนหรือพูดกับ Twin
4. **Detect** — AI ตรวจจับรูปแบบที่คุณมองข้ามหรือไม่เคยเห็น
5. **Adapt** — ประสบการณ์ใน Selfprint ปรับตามคุณแบบ real-time
6. **Guide** — Twin ให้แนวทาง คำถาม มุมมองใหม่
7. **Evolve** — Twin เติบโตไปพร้อมคุณ ยิ่งนาน ยิ่งรู้จักคุณมาก

## บท 02 — Getting Started

### เข้าใช้งานครั้งแรก

เปิด Selfprint ในเบราว์เซอร์ (หรือจาก icon บนหน้าจอมือถือถ้าติดตั้ง PWA แล้ว) ระบบจะพาคุณไปยัง Landing Page อัตโนมัติ

### PDPA & Privacy

ก่อนเริ่มต้น คุณจะเห็นนโยบาย PDPA สั้นๆ ที่อธิบายว่า:
- Selfprint เก็บข้อมูลอะไรบ้าง
- ข้อมูลถูกใช้อย่างไร
- คุณมีสิทธิ์ควบคุมและลบได้เสมอ

กด "ยอมรับ" เพื่อเริ่มต้น หรือไปอ่านรายละเอียดที่ `/privacy`

### สมัคร / Login

Selfprint รองรับ 3 วิธี:
- **Passkey** — ใช้ Face ID / Fingerprint ของมือถือ (แนะนำ — เร็วและปลอดภัยที่สุด)
- **OAuth** — Login ด้วย Google หรือบัญชีที่เชื่อมไว้
- **Magic Link** — รับลิงก์เข้าสู่ระบบทางอีเมล ไม่ต้องจำรหัสผ่าน

### ตั้งค่าโปรไฟล์

หลัง Onboarding เสร็จ คุณสามารถเพิ่มเติมข้อมูลได้ที่หน้า Me (แท็บ "ฉัน"):
- ชื่อที่อยากให้ Twin เรียก
- ภาพโปรไฟล์
- ข้อมูลเพิ่มเติม

### ติดตั้ง PWA

**บน iPhone/iPad:** Safari → แตะ Share → "Add to Home Screen"  
**บน Android:** Chrome → เมนู ⋮ → "Install app" หรือ "Add to Home Screen"  
**บน Desktop:** Chrome → ที่อยู่ URL → ไอคอน Install

หลังติดตั้ง Selfprint เปิดได้เหมือน app ปกติ โหลดเร็วขึ้นมากในการเปิดครั้งถัดไป

## บท 03 — Create Your Selfprint

### เริ่มสร้าง Personal Model

Onboarding มี **7 ขั้นตอน:**

1. **Emotion** — เลือกอารมณ์ตอนนี้ (6 ตัวเลือก)
2. **Nova Conversation** — คุยกับ Nova เพื่อให้รู้จักคุณเบื้องต้น
3. **AI Creation** — เห็นกระบวนการสร้าง Twin แบบ real-time
4. **Blueprint** — InitialBlueprint แสดงโครงร่างตัวตนเบื้องต้น
5. **Fine-tune** — ตอบคำถามปรับแต่งให้แม่นขึ้น
6. **Analysis** — ดู Full Analysis ครั้งแรก
7. **Claim Account** — สร้างบัญชีเพื่อบันทึกข้อมูล (ผ่าน Passkey / OAuth / Magic Link)

### ข้อมูลที่ควรให้ AI

ยิ่งให้ข้อมูลจริงมาก Twin ยิ่งแม่น ข้อมูลที่มีประโยชน์มากที่สุด:

- **อารมณ์ตอนนี้** — ตอบตรงๆ ไม่ต้องเสแสร้ง
- **สิ่งที่อยู่ในใจ** — ปัญหา ความกังวล เป้าหมาย
- **วันเกิด** — ใช้ใน Astrovera Psychology analysis
- **รูปแบบที่รู้ตัวเอง** — "ฉันมักจะ..." หรือ "ฉันไม่ค่อย..."

### การตอบคำถาม / Reflection

ใน Fine-tuning Questions ให้ตอบตามที่รู้สึกจริงๆ ไม่มีคำตอบถูกหรือผิด Nova ใช้คำตอบเหล่านี้สังเคราะห์ Personal Model เบื้องต้น

### Fingerprint Profile คืออะไร

Fingerprint Profile คือโมเดลส่วนตัวที่ AI สังเคราะห์ขึ้นมาจากข้อมูลของคุณ ประกอบด้วย:
- Decision Style (วิธีที่คุณตัดสินใจ)
- Strengths (จุดแข็ง)
- Blind Spots (จุดตาบอด)
- Emotional Range (ช่วงอารมณ์ที่มักพบ)
- Core Values (ค่านิยมหลัก)

Profile นี้จะแม่นยิ่งขึ้นตามเวลาจากการใช้งานและ feedback ที่คุณให้

### ข้อมูลอะไรจำเป็น / อะไรเลือกให้ได้

| ข้อมูล | จำเป็น? | ใช้ทำอะไร |
|---|---|---|
| อารมณ์ตอนนี้ | ✅ จำเป็น | ปรับ Twin บุคลิกตั้งต้น |
| Nova Conversation | ✅ จำเป็น | สร้าง Personal Model เบื้องต้น |
| Fine-tuning answers | ✅ จำเป็น | ปรับ Fingerprint Profile |
| วันเกิด | เลือกได้ | Astrovera Psychology analysis |
| เวลาเกิด / สถานที่ | เลือกได้ | Natal Chart ลึกขึ้น |
| ภาพโปรไฟล์ | เลือกได้ | แสดงในโปรไฟล์ |

## บท 03 — Create Your Selfprint

### ขั้นที่ 2 — Nova Conversation

คุณจะได้คุยกับ **Nova** (ผู้แนะนำ) เพื่อให้ Nova รู้จักคุณเบื้องต้น

### ขั้นที่ 3 — Meet Your AI Twin

**Nova** จะสร้าง **AI Twin** ให้คุณ (หลังจากคุยกับ Nova เสร็จ)  
AI Twin นี้คือฝาแฝดดิจิทัลของคุณ — คุณสามารถตั้งชื่อให้ AI Twin ได้เอง!

> 🔴 **จำให้ขึ้นใจ:** Nova เป็นผู้แนะนำ (Guide) — AI Twin คือฝาแฝดส่วนตัวของคุณ!


AI Twin ของคุณชื่อ **ตั้งเอง** — เป็น AI ที่มีบุคลิกหลายมิติ ปรับตัวได้ตามสถานการณ์ของคุณ

Twin ไม่ใช่ chatbot ทั่วไป Twin:
- รู้จักคุณและจำสิ่งสำคัญเกี่ยวกับคุณ
- ปรับบุคลิกตาม Life Hub ที่คุณอยู่ (12 ด้านชีวิต)
- ปรับโทนตามอารมณ์คุณ (6 mood)
- มีบุคลิกหลักจาก Archetype ที่เหมาะกับคุณ (18 แบบ)

### Twin เรียนรู้คุณอย่างไร

Twin เรียนรู้จาก:
1. **การสนทนา** — ทุกข้อความที่คุณส่ง
2. **Reflection** — สิ่งที่คุณเขียนและบันทึก
3. **Feedback** — เมื่อคุณบอกว่า Insight ตรงหรือไม่
4. **Memory** — สิ่งที่คุณสั่งให้ Twin จำไว้

### Twin Evolution

Twin มี **Maturity Score** (0–100) ที่เพิ่มขึ้นตามการใช้งาน:

| ระดับ | ลักษณะ |
|---|---|
| 0–30 | Twin เพิ่งเกิด เรียนรู้พื้นฐาน |
| 30–60 | Twin เริ่มจำและอ้างอิงบริบทเดิม |
| 60–85 | Twin เข้าใจรูปแบบและคาดการณ์ได้ |
| 85–100 | Twin รู้จักคุณลึกมาก ตอบสนองอย่างแม่นยำ |

Milestones พิเศษ: Twin Awakening (เปิดใช้ Voice + Personality เต็ม), Pattern Visualization (ที่ 30 reflections), Twin Evolution Scene (celebration)

### คุยกับ Twin

ไปที่แท็บ **Chat** (ไอคอนสนทนา) แล้วเริ่มพิมพ์หรือพูดได้เลย

**ตัวอย่างสิ่งที่คุยได้:**
- "วันนี้รู้สึกสับสนกับเรื่องงาน ช่วยคิดด้วยได้ไหม"
- "อยากรู้ว่าตัวเองมีรูปแบบอะไรที่ซ้ำๆ"
- "ช่วยฉันตัดสินใจเรื่อง..."
- "ฉันจำไว้ว่า..." (สั่งให้ Twin จำ)

### พิมพ์ / พูด / ฟัง

- **พิมพ์** — ใช้ช่องข้อความปกติ
- **พูด** — กดไอคอนไมค์ (Voice Input)
- **ฟัง** — Twin ตอบด้วยเสียงเมื่อ Voice Output เปิดอยู่

### เปลี่ยนเสียงและประสบการณ์

ไปที่ Settings → Audio Settings:
- เปิด/ปิด Background Music
- เปิด/ปิด Voice (TTS/STT)
- ปรับระดับเสียง
- เลือกประสบการณ์เสียง (Reflection / Focus / Discovery / Deep Reflection / Celebration)

## บท 05 — Your Space (Dashboard)

### อ่าน Dashboard

Dashboard (`/dashboard`) คือ "Your Space" — พื้นที่ส่วนตัวที่แสดงภาพรวมตัวคุณ ประกอบด้วยส่วนต่างๆ:

### Executive Summary
"สิ่งที่ Selfprint เห็นในตัวคุณตอนนี้" — เขียนเป็นภาษามนุษย์ ไม่ใช่ตัวเลข  
แต่ละ insight มี badge แสดงความมั่นใจ:
- ✓ รู้แน่ — มาจากข้อมูลที่คุณให้โดยตรง
- ~ สรุปจากข้อมูล — AI วิเคราะห์จากรูปแบบ
- ? ยังไม่ทราบ — ยังไม่มีข้อมูลพอ

### Full Analysis
คลิก "อ่านการวิเคราะห์เต็ม" → ไปหน้า `/analysis`  
แสดง: Decision Style, Strengths, Insights, Opportunities, Blind Spots

### Behavioral Patterns
รูปแบบพฤติกรรมที่ AI ตรวจจับได้ เช่น:
- "ความมั่นใจของคุณลดลงเวลารู้สึกเครียด"
- "คุณตัดสินใจได้ดีที่สุดในด้านอาชีพ"

### Personal Insights
Insight ที่เฉพาะเจาะจงกับสถานการณ์ปัจจุบัน

### Growth
เห็นพัฒนาการตามเวลา — autonomy trend, confidence trend

### Recent Memories
ความทรงจำล่าสุดที่คุณบันทึกและที่ Twin จำ

### Small Wins
ความสำเร็จเล็กๆ ที่ AI เห็นและบันทึก

### Personal Guidance
คำแนะนำจาก Twin ตามสถานการณ์ปัจจุบัน

## บท 06 — Reflect

### เขียน Reflection

Reflection คือการบันทึกความคิด ความรู้สึก หรือสิ่งที่เกิดขึ้นในชีวิต เพื่อให้ Twin วิเคราะห์และให้ Insight

**วิธีเขียน:** ไปที่ Chat → เขียนสิ่งที่อยู่ในใจตามธรรมชาติ ไม่ต้องมีโครงสร้าง

### Voice Reflection

กดไอคอนไมค์ใน Chat แล้วพูดออกมา Selfprint จะแปลงเสียงเป็นข้อความและส่งให้ Twin วิเคราะห์

### คำถามสะท้อนตัวเอง

Twin จะถามคำถามปลายเปิดที่ชวนคิด เช่น:
- "ส่วนไหนของตัวเองที่คุณไม่ยอมรับ?"
- "ถ้าเอาความกลัวออกไป คุณจะเลือกอะไร?"
- "คุณหมายถึงอะไรกับ [ค่านิยมที่พูดถึง]?"

ตอบตรงๆ ได้เลย ไม่มีคำตอบที่ผิด

### ให้ AI วิเคราะห์สิ่งที่คุณเขียน

หลังส่งข้อความ Twin จะ:
1. สะท้อนสิ่งที่คุณพูดกลับมา
2. ถามคำถามที่ลึกขึ้น
3. ระบุ Pattern ถ้าเห็น
4. ให้มุมมองใหม่

### เปลี่ยน Reflection เป็น Insight

เมื่อ Reflection สะสมพอ (6+ ครั้ง) AI จะตรวจจับ Pattern และแสดงบน Dashboard เป็น Insight อัตโนมัติ

## บท 07 — Memory

### AI จำอะไรได้บ้าง

Twin จำทุกอย่างที่คุณบอก (ใน Plus plan ขึ้นไป) ผ่านระบบ Memory 4 ประเภท:

| ประเภท | ตัวอย่าง |
|---|---|
| **small_win** | "ฉันปีนเขาได้เป็นครั้งแรก" |
| **important_moment** | "ได้งานใหม่", "แยกทางกับแฟน" |
| **discovery** | "รู้ว่าตัวเองชอบการเขียน" |
| **personal** | "ครอบครัวสำคัญมากสำหรับฉัน" |

### เพิ่ม Memory

**วิธีที่ 1 — บอก Twin ตรงๆ:** "จำไว้ว่าฉัน..." หรือ "บันทึกว่า..."  
**วิธีที่ 2 — จาก Dashboard:** ส่วน "Recent Memories" → กด + เพิ่ม

### แก้ไข / ลบ Memory

ไปที่ Memory section ใน Dashboard → กดที่ Memory ที่ต้องการ → แก้ไขหรือลบ

### สั่งให้ Twin จำ

พิมพ์ใน Chat: "จำไว้ว่า [สิ่งที่ต้องการจำ]"  
ตัวอย่าง: "จำไว้ว่าฉันกลัวการพูดในที่สาธารณะ แต่อยากแก้ให้ได้"

### ควบคุมสิ่งที่ AI จำ

ไปที่ Privacy Center (`/privacy`) → AI Memory section → ดู / แก้ไข / ลบ memory ทั้งหมดได้

## บท 08 — Patterns & Insights

### Pattern คืออะไร

Pattern คือรูปแบบพฤติกรรมที่ซ้ำๆ ที่ AI ตรวจจับได้จากข้อมูลการสนทนาและ decision history  
ตัวอย่าง Pattern:
- "คุณมั่นใจน้อยลงเวลาเครียด" (mood_confidence pattern)
- "autonomy ของคุณเพิ่มขึ้นตลอด 3 เดือนที่ผ่านมา" (autonomy_trend)
- "คุณตัดสินใจได้ดีที่สุดในด้านอาชีพ" (hub_autonomy)

### AI ตรวจจับ Pattern อย่างไร

AI ใช้ข้อมูลจาก decision log ของคุณ:
- **Minimum 6 ข้อมูล** — ก่อนแสดง Pattern ใดๆ
- **Minimum 3 ข้อมูล** — ต่อ mood หรือ hub เพื่อ group pattern
- ห้ามสร้าง Pattern จาก noise — AI จะไม่แสดงถ้าไม่มีข้อมูลพอ

### อ่าน Insight

แต่ละ Insight มี confidence badge:
- **✓ รู้แน่** = ข้อมูลตรงๆ จากคุณ
- **~ สรุปจากข้อมูล** = AI วิเคราะห์จาก patterns
- **? ยังไม่ทราบ** = ต้องใช้งานต่อเพื่อสะสมข้อมูล

### ตรวจสอบว่า Insight ตรงกับคุณหรือไม่

ทุก Insight มีปุ่ม feedback ให้เลือก:
- **ตรงมาก** — very_true
- **พอใช้** — somewhat
- **ไม่แน่ใจ** — not_sure
- **ไม่ใช่ฉัน** — not_me

### Feedback ให้ AI

เลือก feedback แล้ว AI จะปรับ Personal Model อัตโนมัติ ครั้งถัดไป Insight จะแม่นขึ้น

## บท 10 — Adaptive Selfprint

### AI เลือก Hub อย่างไร

ครั้งแรกที่เข้าใช้งาน (เซสชันแรกเท่านั้น) AI อาจแนะนำ Hub ที่เหมาะกับบริบทคุณ  
หลังจากนั้น คุณเป็นคนเลือก Hub เอง — AI ไม่เคย override การเลือกของคุณ

### AI เข้าใจอารมณ์ / Context อย่างไร

AI ติดตาม:
- Mood ที่คุณเลือก (6 ตัวเลือก)
- Hub ที่คุณอยู่ (12 ด้านชีวิต)
- เวลาของวัน (เช้า / กลางวัน / เย็น / ค่ำ)
- ประวัติการใช้งาน

สิ่งเหล่านี้ถูกนำมาคำนวณเป็น "Experience Configuration" ที่ปรับ UI ให้เหมาะกับคุณ

### Theme ที่เปลี่ยนตามคุณ

สี, Gradient, แสง เปลี่ยนตาม Hub + Mood + เวลาของวันผ่าน CSS variables  
ตัวอย่าง: Hub "Creativity" + Mood "Confident" → ธีมที่สว่าง มีพลังงาน

### Background / Animation

Environment Engine ปรับ Background animation และ Ambient effects ตาม context

### Music / Ambient

Audio Engine เลือก Background music ตาม Experience:
- **Reflection** → Piano / Ambient เบาๆ
- **Focus** → Minimal Pulse
- **Discovery** → Cosmic Ambient
- **Deep Reflection** → Sparse Ambient
- **Celebration** → Cinematic Uplift

### Notifications

**Daily Brief** (`/brief`) — สรุปประจำวันพร้อมเสียง ส่งมาให้ตาม schedule

### ประสบการณ์ที่ปรับเฉพาะบุคคล

ทุกอย่างใน Selfprint ปรับตามคุณโดยไม่ต้องตั้งค่าเอง:
- ธีม / สี
- เสียงพื้นหลัง
- โทนที่ Twin พูด
- Insight ที่แสดง
- Hub ที่แนะนำ (เซสชันแรก)

## บท 12 — Voice & Audio

### Voice Mode

Voice Mode ให้คุณ:
- พูดกับ Twin (Speech-to-Text)
- ให้ Twin ตอบด้วยเสียง (Text-to-Speech)
- ฟัง Daily Brief ด้วยเสียง

### พูดกับ Twin

ใน Chat → กดไอคอนไมค์ → พูด → ปล่อยมือ → Twin วิเคราะห์และตอบ

### ฟัง Twin

เมื่อ Voice Output เปิดอยู่ Twin จะอ่านคำตอบออกมาเป็นเสียงอัตโนมัติ  
**Audio Ducking:** เสียงพื้นหลังจะเบาลงอัตโนมัติเมื่อ Twin พูด

### Background Music

เปิด/ปิดได้ที่ Audio Settings → Background Music toggle  
ระดับเสียงปรับได้ (0–100)

### Ambient Sound

เสียง Ambient ปรับตาม Hub + Mood อัตโนมัติ  
ปิดได้ใน Audio Settings

### ปรับเสียงและประสบการณ์

Audio Settings (กดไอคอนเสียงหรือไปที่ Settings):
- Master Volume
- Music On/Off
- Sound On/Off
- Voice On/Off
- Reduce Motion (accessibility)

## บท 13 — Understanding Your Analysis

### Executive Summary

ส่วนแรกของ Dashboard — เขียนเป็นประโยคภาษามนุษย์ ไม่ใช่กราฟหรือตาราง  
อ่านแล้วควรรู้สึกว่า "ใช่ นั่นแหละฉัน" (ถ้า data พอ)

### Deep Analysis

หน้า `/analysis` — รายละเอียดเต็ม:
- Decision Style — คุณตัดสินใจแบบไหน
- Strengths — จุดแข็งที่ AI เห็น
- Insights — สิ่งที่น่าสนใจเกี่ยวกับคุณ
- Opportunities — โอกาสพัฒนา
- Blind Spots — จุดตาบอดที่อาจมองข้าม

### Confidence / Signal

แต่ละ insight มี Knowledge Level:

| ระดับ | ความหมาย | ควรทำอะไร |
|---|---|---|
| ✓ รู้แน่ | มาจากข้อมูลที่คุณบอกตรงๆ | เชื่อถือได้ |
| ~ สรุปจากข้อมูล | AI วิเคราะห์จาก patterns | พิจารณาและ feedback |
| ? ยังไม่ทราบ | ข้อมูลยังไม่พอ | ใช้งานต่อเพื่อสะสมข้อมูล |

### Insight vs Fact

- **Fact** = สิ่งที่คุณบอกโดยตรง เช่น "ฉันบอกว่าฉันชอบงานคนเดียว"
- **Insight** = สิ่งที่ AI สรุปจากรูปแบบ เช่น "คุณทำงานได้ดีที่สุดในสภาพแวดล้อมที่เงียบ"

### วิธีอ่านคำแนะนำของ AI

Twin ไม่บอกว่า "ควรทำแบบนี้" — Twin จะ:
1. สะท้อนสิ่งที่คุณพูดกลับ
2. ถามคำถามชวนคิดลึกขึ้น
3. ให้มุมมองใหม่
4. คืนการตัดสินใจให้คุณเสมอ

### ทำอย่างไรเมื่อ AI วิเคราะห์ไม่ตรง

1. กด feedback "ไม่ใช่ฉัน" หรือ "ไม่แน่ใจ"
2. อธิบายเพิ่มเติมใน Comment (ถ้ามี)
3. บอก Twin ใน Chat ว่า "นั่นไม่ตรงกับฉัน เพราะ..."
4. AI จะปรับ Personal Model อัตโนมัติ

## บท 14 — Privacy & Control

### ข้อมูลของคุณถูกใช้อย่างไร

Selfprint ใช้ข้อมูลของคุณเพื่อ:
- ปรับ Twin ให้เข้าใจคุณมากขึ้น
- สร้าง Insight และ Pattern ที่เฉพาะสำหรับคุณ
- ปรับประสบการณ์ (ธีม, เสียง, เนื้อหา)

Selfprint **ไม่** ใช้ข้อมูลของคุณเพื่อ:
- โฆษณา
- ขายให้บุคคลที่สาม
- เปรียบเทียบกับผู้ใช้คนอื่น

### PDPA

Selfprint ปฏิบัติตาม พ.ร.บ. คุ้มครองข้อมูลส่วนบุคคล (PDPA):
- เก็บข้อมูลเท่าที่จำเป็น
- แจ้งวัตถุประสงค์ก่อนเก็บ
- ผู้ใช้มีสิทธิ์เข้าถึง แก้ไข ลบข้อมูล

### AI Memory

ควบคุมที่ Privacy Center (`/privacy`) → AI Memory:
- ดู memory ทั้งหมดที่ AI จำ
- ลบ memory ที่เฉพาะเจาะจง
- ปิด AI Memory ทั้งหมด (Twin จะจำข้ามเซสชันไม่ได้)

### Personal Model

ที่ Privacy Center → Personal Model:
- ดู Fingerprint Profile ของคุณ
- Reset Personal Model (เริ่มต้นใหม่)
- Export ข้อมูล

### Fingerprint / Biometric

ถ้าใช้ Passkey (Face ID / Fingerprint) สำหรับ Login:
- Biometric data ไม่ถูกส่งออกจากอุปกรณ์ของคุณ
- Selfprint ได้รับแค่ token ยืนยัน ไม่ได้รับข้อมูล biometric จริง

### Consent

ดูและแก้ไข consent ที่ Privacy Center → Consent Management  
คุณสามารถถอน consent ได้ตลอดเวลา

### Export Data

Privacy Center → Export Data → ดาวน์โหลดข้อมูลทั้งหมดเป็นไฟล์ JSON

### Delete Data

Privacy Center → Delete Account → ลบข้อมูลทั้งหมดถาวร (ไม่สามารถกู้คืนได้)

### Reset Selfprint

Privacy Center → Reset Selfprint → เริ่มต้นใหม่ทั้งหมดโดยไม่ลบบัญชี  
Personal Model, Memory, และ Patterns จะถูก reset — Twin เริ่มเรียนรู้ใหม่จากศูนย์

## บท 16 — Troubleshooting

### AI ไม่ตอบ

1. ตรวจสอบ Internet connection
2. Refresh หน้า (F5 หรือ pull-to-refresh)
3. ถ้ายังไม่ตอบ → ลอง logout แล้ว login ใหม่
4. ตรวจสอบ status ที่ Selfprint Status page

### Voice ใช้ไม่ได้

1. ตรวจสอบว่าเบราว์เซอร์ได้รับ permission ไมค์  
   Chrome: Settings → Privacy → Microphone → ตรวจสอบว่า Selfprint อนุญาต
2. ตรวจสอบว่า Voice เปิดอยู่ใน Audio Settings
3. ลอง reload หน้า

### Twin ไม่โหลด

1. Refresh หน้า
2. ล้าง Cache ของเบราว์เซอร์
3. ถ้า Twin Evolution Scene ค้าง → reload ปกติ หน้าจะกลับมา

### Notification ไม่มา

1. ตรวจสอบว่า Browser notification permission เปิดอยู่  
2. ตรวจสอบว่า PWA ติดตั้งแล้ว (notification ทำงานดีกว่าบน installed PWA)
3. iOS: ต้องติดตั้ง PWA ก่อนถึงจะรับ notification ได้

### PWA มีปัญหา

1. ลบ PWA แล้วติดตั้งใหม่
2. Safari (iOS): Settings → Clear History and Website Data → ติดตั้ง PWA ใหม่
3. Chrome (Android): Chrome Menu → More tools → Clear browsing data → ติดตั้ง PWA ใหม่

### Login / Passkey

- **Passkey ไม่ทำงาน:** ตรวจสอบว่า Face ID / Fingerprint เปิดอยู่บนอุปกรณ์
- **Magic Link หมดอายุ:** ขอ link ใหม่ได้เสมอ (link มีอายุ 1 ชั่วโมง)
- **OAuth ไม่ connect:** ตรวจสอบ permission ของ Google account

### Internet / Offline

Selfprint ใช้งาน Core Experience ได้บางส่วนแม้ offline (ผ่าน PWA Cache)  
แต่การสนทนากับ Twin ต้องการ Internet เสมอ (AI ประมวลผลบน Cloud)

### หลักการพื้นฐาน

> **ยิ่ง Selfprint รู้จักคุณมาก → Personal Model ยิ่งแม่น → Twin ยิ่งเป็นคุณ**

### ✅ สิ่งที่ควรทำ

**1. เขียน Reflection อย่างสม่ำเสมอ**  
อย่างน้อย 3–4 ครั้งต่อสัปดาห์ ไม่ต้องยาว แค่บอก Twin ว่าวันนี้คิดอะไร รู้สึกอะไร  
Pattern ที่ดีต้องการ minimum 6 data points — ยิ่ง reflect บ่อย AI ยิ่งเห็น pattern ชัด

**2. บอกบริบทจริง**  
อย่า filter ว่า "ควรบอก AI ไหม" — บอกทุกอย่างที่คิด รวมถึงความรู้สึกที่ขัดแย้งกัน  
AI ไม่ตัดสิน และยิ่งรู้บริบทจริงมาก ยิ่งให้ Insight ที่ตรงกว่า

**3. ให้ Feedback AI อย่างสม่ำเสมอ**  
เมื่อเห็น Insight → กด feedback ว่าตรงไหม  
"ไม่ใช่ฉัน" มีประโยชน์เท่ากับ "ตรงมาก" — ทั้งสองอย่างช่วย Personal Model ปรับ

**4. บันทึกเหตุการณ์สำคัญ**  
ได้งานใหม่ / ตัดสินใจครั้งใหญ่ / เรียนรู้สิ่งสำคัญ → บันทึกเป็น Memory ไว้  
Twin จะใช้เหตุการณ์เหล่านี้เป็น anchor point ในการเข้าใจคุณ

**5. กลับมาใช้งานต่อเนื่อง**  
ประโยชน์ของ Selfprint ไม่ใช่แค่การสนทนาครั้งเดียว แต่คือการสะสม  
Twin ที่ใช้งาน 3 เดือนจะเข้าใจคุณแตกต่างจาก Twin ที่ใช้แค่ 3 วันอย่างสิ้นเชิง

**6. แก้ข้อมูลที่ไม่ตรง**  
ถ้า Twin เข้าใจผิดอะไร → บอกทันที "นั่นไม่ตรงกับฉัน เพราะ..."  
AI ออกแบบมาให้เรียนรู้จาก correction ไม่แพ้จาก confirmation

**7. เปลี่ยน Hub ตามบริบท**  
ถ้าคิดเรื่องงาน → เปลี่ยนไปที่ Career Hub  
ถ้าคิดเรื่องความสัมพันธ์ → Relationship Hub  
Twin จะปรับโทนและวิธีถามตาม Hub นั้นโดยอัตโนมัติ

**8. ทดลอง Voice Mode**  
การพูดออกมาให้ AI ฟังบางครั้งดึงความคิดที่ "ยังไม่เป็นคำ" ออกมาได้ดีกว่าการพิมพ์

### ❌ สิ่งที่ไม่ควรทำ

- **ตอบในสิ่งที่คิดว่า AI อยากได้ยิน** — ตอบตรงๆ ดีกว่า
- **ใช้งานแค่เป็นครั้งคราว** — Pattern detection ต้องการความต่อเนื่อง
- **เพิกเฉยต่อ Insight ที่ดูแปลก** — บางครั้ง AI เห็นสิ่งที่คุณมองข้ามจริงๆ แต่ก็ให้ feedback ถ้าไม่ตรง
- **ลืม feedback** — การ feedback คือการสอน AI ให้รู้จักคุณดีขึ้น

## Personal Model คืออะไร

Personal Model คือโมเดล AI ที่สร้างขึ้นเฉพาะสำหรับคุณ ประกอบด้วย:

- **Values** — ค่านิยมที่ AI สรุปจากสิ่งที่คุณพูดและเลือก
- **Goals** — เป้าหมายที่ AI เห็น (ระยะสั้น / ยาว)
- **Strengths** — จุดแข็งที่แสดงออกในการสนทนา
- **Blind Spots** — รูปแบบที่คุณมักไม่เห็น
- **Emotional Range** — ช่วงอารมณ์ที่มักพบ
- **Decision Style** — วิธีที่คุณตัดสินใจ (Intuitive, Analytical, Collaborative, etc.)

โมเดลนี้ถูก build จาก: Onboarding data + การสนทนา + feedback + memories

## AI Memory — ระบบหน่วยความจำ

AI Memory แตกต่างจาก "chat history" ธรรมดา:

| Chat History | AI Memory |
|---|---|
| บันทึกข้อความทั้งหมด | บันทึกเฉพาะสิ่งสำคัญ |
| ค้นหาได้จาก keyword | สังเคราะห์เป็นความเข้าใจ |
| ล้างเมื่อเซสชันจบ (บางระบบ) | ข้ามเวลา ข้ามเซสชัน |
| ไม่มี type classification | แยกเป็น 4 ประเภท |

Selfprint ใช้ Memory 4 ประเภท ในการ build context ให้ Twin ก่อนตอบสนอง

## Pattern Detection — วิธีที่ AI ตรวจจับรูปแบบ

AI วิเคราะห์ข้อมูลจาก decision log:
- ทุกการสนทนาบันทึก `autonomy_level` (ระดับความเป็นตัวเอง) และ `confidence`
- หลัง 6+ conversations → AI วิเคราะห์ว่ามี trend อะไร
- แยก pattern ตาม hub และ mood เพื่อ insight ที่เฉพาะเจาะจง

ความสำคัญ: minimum data ป้องกันไม่ให้ AI แสดง "pattern ปลอม" จาก noise

## Twin Evolution — กระบวนการวิวัฒนาการ

Twin มี lifecycle:

1. **Born** — สร้างจาก Onboarding data, Maturity Score = 30
2. **Growing** — Maturity เพิ่มจากการสนทนาและ feedback
3. **Awakening** — Twin Awakening event → Voice + Personality เต็มรูปแบบ
4. **Pattern Recognition** — Twin เริ่มเห็นรูปแบบ → Pattern Visualization unlocked
5. **Evolution** — ที่ 30 reflections → Twin Evolution Scene (celebration)
6. **Mature** — Maturity 85–100 → Twin รู้จักคุณลึกมาก

## Privacy Architecture

Selfprint ออกแบบ Privacy จากภายใน:

- **Data Minimization** — เก็บเท่าที่จำเป็น
- **Purpose Limitation** — ใช้ข้อมูลตามที่แจ้งเท่านั้น
- **User Control** — ผู้ใช้ export / delete ได้ทุกเวลา
- **Biometric** — Passkey data ไม่ออกจากอุปกรณ์
- **AI Processing** — ประมวลผล AI บน Cloud แต่ไม่ share กับบุคคลที่สาม

## AI Analysis Methodology

Selfprint ใช้ **Evidence-Based Insight** — ทุก insight ต้องมี evidence:

- KNOW: มี direct evidence จากคุณ
- INFER: มี indirect evidence จาก patterns (ต้องผ่าน minimum data threshold)
- UNKNOWN: ไม่มี evidence พอ → แสดงว่า "ยังไม่ทราบ" แทนที่จะแต่งขึ้น

**ห้ามแต่ง Insight** — นี่คือ core principle ของ Selfprint AI ทุกตัว
