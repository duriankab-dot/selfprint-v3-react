# คู่มือผู้ใช้ Selfprint (Phase 5.9)

คู่มือนี้อธิบายฟีเจอร์หลักของ Selfprint สำหรับผู้ใช้จริง — Hub, Mood, Prototype Core (archetype), Dashboard, Ask Coach และปัญหาที่พบบ่อย เขียนคู่กับ `docs/HANDOFF_2026-08-09_PHASE5_UNIFIED.md` ซึ่งเป็นเอกสารสำหรับทีมพัฒนา (technical handoff) ส่วนไฟล์นี้เขียนสำหรับผู้ใช้ปลายทาง

---

## Selfprint คืออะไร

Selfprint คือ AI Twin ส่วนตัวที่ช่วยให้คุณเข้าใจตัวเอง ตัดสินใจ และติดตามรูปแบบความเป็นอิสระ (autonomy) ของตัวเองเมื่อเวลาผ่านไป ผ่านการสนทนากับ "Nova" — AI ที่ปรับบุคลิกตาม Hub (หัวข้อที่คุย) และ Mood (อารมณ์ตอนนั้น) ของคุณ

---

## Hub ทั้ง 12 หัวข้อ

แต่ละ Hub คือหัวข้อชีวิตที่คุณเลือกคุยกับ Nova ได้ Nova จะปรับบุคลิก/น้ำเสียงตาม Hub ที่เลือก:

| Hub | ชื่อ | เกี่ยวกับ |
|---|---|---|
| 🪞 identity | ตัวตน | สำรวจว่าฉันเป็นใคร |
| 🧭 decision | การตัดสินใจ | ช่วยแยกปัญหา ตัดสินใจ |
| 🌉 relationship | ความสัมพันธ์ | เข้าใจตัวเองกับคนอื่น |
| 🎓 career | อาชีพ | พัฒนาการงาน |
| 💚 health | สุขภาพ | ดูแลร่างกาย-ใจ |
| 💰 money | เงินตรา | จัดการเงินให้สอดคล้องค่านิยม |
| 🤖 ai-twin | AI Twin | คุยกับ Nova โดยตรงเรื่องความสัมพันธ์ระหว่างคุณกับ AI |
| 📚 learning | การเรียนรู้ | ขยายความเข้าใจ เรียนรู้เรื่องใหม่ |
| 🎨 creativity | ความสร้างสรรค์ | ปลดปล่อยจินตนาการ |
| ✨ spirituality | ความเป็นอยู่ | ค้นหาความหมายและจุดประสงค์ |
| 🌍 impact | ผลกระทบ | อยากทำให้โลกดีขึ้นยังไง |
| ⏰ activities | กิจกรรม | บริหารจัดการเวลา/นิสัย |

เปลี่ยน Hub ได้ทุกเมื่อจากหน้า Chat (แถบด้านซ้าย) — ระบบจะจำ Hub ล่าสุดที่ใช้ไว้ให้อัตโนมัติ

## Mood ทั้ง 6 แบบ

ก่อนคุยกับ Nova ระบบจะถามว่าวันนี้คุณรู้สึกยังไง — คำตอบมีผลต่อวิธีที่ Nova ตอบ (พูดช้าลงถ้าเครียด, ท้าทายมากขึ้นถ้าพร้อม ฯลฯ):

- **stressed** (เครียด) — Nova จะพูดช้าลง โฟกัสทีละเรื่อง
- **confused** (สับสน) — Nova จะแยกเป็นเรื่องเล็ก ๆ อธิบายทีละขั้น
- **confident** (มั่นใจ) — Nova จะท้าทายให้ก้าวต่อ
- **drained** (หมดแรง) — Nova จะให้คำแนะนำสั้น เบา ไม่กดดัน
- **ready** (พร้อม) — Nova จะถามคำถามใหญ่ ชวนคิดไกล
- **reflective** (อยากคิดลึก) — Nova จะพาสำรวจความซับซ้อน ไม่รีบ

เปลี่ยน mood ได้ทุกเมื่อ ไม่ต้องรอ session ใหม่

## Prototype Core (Archetype)

Selfprint คำนวณ "Prototype Core" ของคุณจาก **Life Path Number** (ตัวเลขที่ได้จากวันเกิดจริงของคุณ ผ่านสูตร numerology) แล้ว map เข้ากับ 1 ใน 12 archetype แบบ Jungian — เป็นการคำนวณที่กำหนดแน่นอน (deterministic) จากวันเกิด ไม่ใช่การสุ่มหรือทายจากคำตอบแบบทดสอบ:

| Life Path | Archetype |
|---|---|
| 1 | Hero (วีรบุรุษ) |
| 2 | Lover (คู่รัก) |
| 3 | Jester (ตัวตลก) |
| 4 | Everyman (คนธรรมดา) |
| 5 | Explorer (นักสำรวจ) |
| 6 | Caregiver (ผู้ดูแล) |
| 7 | Sage (นักปราชญ์) |
| 8 | Ruler (ผู้ปกครอง) |
| 9 | Innocent (ผู้บริสุทธิ์) |
| 11 | Magician (นักมายากล) |
| 22 | Creator (ผู้สร้างสรรค์) |
| 33 | Outlaw (ผู้ท้าทายกฎ) |

Prototype Core จะแสดงในส่วน "AI Twin ของคุณ" บน Dashboard พร้อม % ความแม่นยำ (accuracy) — เลขนี้สะท้อนว่า Selfprint มั่นใจแค่ไหนในบทวิเคราะห์ ไม่ใช่ตัวเลขคงที่ตายตัว (ยิ่งกรอกวันเกิดจริงและตอบคำถาม fine-tune ครบ ยิ่งแม่นขึ้น)

## Dashboard

หน้า Dashboard (`/dashboard`) มีส่วนต่าง ๆ ดังนี้:

- **AI Twin ของคุณ** — Prototype Core, รูปแบบการตัดสินใจ, จุดแข็ง/จุดที่ควรระวัง, ปุ่มส่งออก Blueprint และแชร์
- **ถาม Coach (Ask Coach)** — ถามคำถามเชิงการตัดสินใจ ได้คำตอบที่อิงจาก Life Path profile ของคุณ + รูปแบบที่พบจากประวัติการใช้งานจริง (ถ้ามีข้อมูลพอ) — ฟีเจอร์นี้เปิดแบบทยอย (staged rollout) จึงอาจยังไม่ปรากฏสำหรับทุกคนในทันที
- **ภาพรวมพฤติกรรมการใช้งาน** — สรุป Hub ที่ใช้บ่อยที่สุด, จำนวนครั้งที่เปลี่ยน mood, สัดส่วนคำตอบที่คุณให้ 👍/👎 กับ Nova, และความแม่นยำ AI Twin ล่าสุด (แสดงเมื่อมีข้อมูลการใช้งานแล้วเท่านั้น)
- **ข้อมูลเชิงลึกของคุณ** — สรุปสถิติ: จำนวนการโต้ตอบ, ความเป็นอิสระเฉลี่ย, ความมั่นใจเฉลี่ย, Hub/Mood ที่ใช้บ่อยที่สุด
- **แนวโน้มความเป็นอิสระ** — กราฟแสดงระดับความเป็นอิสระ (autonomy) เมื่อเวลาผ่านไป
- **รูปแบบที่พบ** — ข้อสังเกตอัตโนมัติเมื่อพบว่าความเป็นอิสระ/ความมั่นใจของคุณเปลี่ยนแปลงอย่างมีนัยสำคัญ (ต้องมีประวัติอย่างน้อย 6 ครั้งขึ้นไปถึงจะแสดง กันไม่ให้สรุปเร็วเกินไปจากข้อมูลน้อย)
- **บันทึกการตัดสินใจ** — ตารางประวัติการสนทนาทุกครั้ง กรองตาม Hub/Mood/วันที่ได้
- **ส่งออกข้อมูล** — ดาวน์โหลดประวัติเป็น CSV หรือ JSON

## ถาม Coach (Ask Coach)

ฟีเจอร์ให้ถามคำถามเชิงการตัดสินใจแบบอิสระ (ไม่ต้องเลือก Hub/Mood ก่อน) แล้วได้คำตอบที่อ้างอิงจาก:
1. Life Path profile ของคุณ (จุดแข็ง/จุดที่ควรระวัง จากวันเกิดจริง)
2. รูปแบบที่พบจากประวัติการใช้งานจริงของคุณ (ถ้ามีข้อมูลพอ — ไม่ fabricate รูปแบบจากข้อมูลน้อยเกินไป)

**เงื่อนไขการใช้งาน:** ต้อง login แล้ว และมีวันเกิดบันทึกไว้ในโปรไฟล์ (ทำ onboarding ให้ครบ)

**หมายเหตุ:** ฟีเจอร์นี้เปิดใช้งานแบบทยอย (staged rollout 10% → 50% → 100%) เพื่อดูผลตอบรับก่อนเปิดให้ทุกคน — ถ้ายังไม่เห็นส่วนนี้บน Dashboard แปลว่ายังไม่ถึงคิวเปิดให้บัญชีของคุณ

## คำถามที่พบบ่อย (Troubleshooting)

**Dashboard ว่างเปล่า ไม่มีข้อมูลอะไรเลย**
ต้อง login (ผ่าน magic link) ก่อน และต้องเคยคุยกับ Nova อย่างน้อย 1 ครั้งหลัง login แล้ว — ข้อมูลที่คุยตอนยังไม่ login จะไม่ถูกบันทึกจนกว่าจะสร้างบัญชี

**ไม่เห็นปุ่ม "ถาม Coach"**
ดูหัวข้อ "ถาม Coach" ด้านบน — ฟีเจอร์เปิดแบบทยอย อาจยังไม่ถึงคิวบัญชีของคุณ หรือยังไม่ได้กรอกวันเกิดในโปรไฟล์

**AI Twin ยังไม่มีข้อมูล / บอกให้ทำ onboarding**
ต้องทำ onboarding ให้ครบ (กรอกวันเกิด + เช็คอินอารมณ์ + ตอบคำถาม fine-tune) แล้ว claim บัญชีด้วยอีเมล (magic link) เพื่อบันทึกผลถาวร — ถ้าปิดเบราว์เซอร์ก่อน claim บัญชี ข้อมูลจะหายไป

**"รูปแบบที่พบ" ไม่แสดงอะไรเลยทั้งที่คุยไปหลายครั้งแล้ว**
ต้องการประวัติอย่างน้อย 6 ครั้งขึ้นไป และความเปลี่ยนแปลงต้องมีนัยสำคัญพอ (ไม่ใช่แค่ noise เล็กน้อย) — ถ้าความเป็นอิสระ/ความมั่นใจของคุณค่อนข้างคงที่ตลอด จะไม่มีอะไรให้แสดง ซึ่งเป็นเรื่องปกติ

**Magic link หมดอายุ / ไม่ได้รับอีเมล**
ลองขอ magic link ใหม่จากหน้า claim account — ลิงก์มีอายุจำกัด เช็ค spam folder ด้วย

**คำถามบางคำถามถูก Nova/Coach ปฏิเสธไม่ตอบตรง ๆ**
ระบบมีชั้นกรองความปลอดภัย (Safety Layer) สำหรับคำถามที่เกี่ยวกับการทำร้ายตัวเอง การพนัน การลงทุน หรือการแพทย์ที่มีความเสี่ยงสูง — จะได้รับข้อความแนะนำแหล่งช่วยเหลือที่เหมาะสมแทนคำตอบตรง ๆ (เช่น สายด่วนสุขภาพจิต 1323 สำหรับกรณีวิกฤต)
