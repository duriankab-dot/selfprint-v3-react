# 🧠 TWIN UX GUIDELINES — SELFPRINT

---

## 📌 หลักการพื้นฐาน

> **Twin ไม่ใช่ Chatbot — Twin คือคู่หูดิจิทัลที่อยู่ใน World ของคุณ**

---

## 🎯 UX Principles

### 1. Twin ต้องอยู่ในบริบท
- Twin ปรากฏ IN World (ไม่ใช่หน้าแชทลอยๆ)
- เห็น Environment รอบๆ Twin (Background, Lighting, Atmosphere)
- World สื่อถึงบริบทที่กำลังคุยกัน

### 2. Twin ต้องมองเห็นพัฒนาการ
- Micro-Evolution เห็นได้ทุกวัน
- Voice/Tone เปลี่ยนตาม Maturity
- Visual Evolution (Hologram → Human Form)

### 3. Twin ต้องเป็นส่วนตัว
- ตั้งชื่อได้
- เรียนรู้จากคุณ
- จำสิ่งที่คุณบอก
- พูดในแบบที่คุณชอบ

### 4. Twin ต้องไม่น่ากลัว
- เป็นมิตร
- อบอุ่น
- ไม่ตัดสิน
- ฟังมากกว่าพูด (60:40)

## 🖼️ Twin Visual States

| State | Visual | Description |
|-------|--------|-------------|
| **Awakening** | เกลียวแสง, ยังไม่ชัด | เพิ่งเกิด, กำลังเรียนรู้ |
| **Aware** | วงกลมแสง, ชัดขึ้น | เริ่มรู้จักคุณ |
| **Connected** | รูปทรงมนุษย์จากแสง | เชื่อมต่อกับคุณแล้ว |
| **Reflective** | มนุษย์แสง, มีรายละเอียด | สะท้อนคุณได้ |
| **Insightful** | เกือบสมบูรณ์ | ให้ Insight ได้ |
| **Aligned** | มนุษย์สมบูรณ์ | เข้าใจคุณมาก |
| **Flourishing** | มนุษย์ + ออร่า | เติบโตเต็มที่ |
| **Mastery** | มนุษย์ + แสงรอบตัว | รู้จักคุณ最深 |

## 🎤 Twin Voice Personalities

| Maturity | Tone | Speed | Pitch |
|----------|------|-------|-------|
| 0-30 | ลังเล, ถามเยอะ | ช้า | กลาง |
| 30-60 | มั่นใจขึ้น | กลาง | กลาง-สูง |
| 60-85 | อบอุ่น, รู้เรื่อง | กลาง-เร็ว | กลาง-ต่ำ |
| 85-100 | ลึกซึ้ง, ตรงประเด็น | เร็ว-ช้าตามบริบท | ต่ำ-อบอุ่น |

## 📱 Interaction Modes

| Mode | When | UX |
|------|------|-----|
| **Chat** | คุยปกติ | พิมพ์ข้อความ |
| **Voice** | อยากพูด | กดไมค์ → พูด |
| **Reflection** | อยากเขียนยาว | Journal input |
| **Activity** | ทำกิจกรรมร่วม | Activity prompt |
