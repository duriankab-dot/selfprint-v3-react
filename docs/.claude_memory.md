## 🧩 Supabase Edge Functions (ทั้งหมด 12 ฟังก์ชัน)

```
supabase/functions/
├── auth-registration-options  → WebAuthn registration options
├── auth-register-passkey      → Register passkey
├── auth-authentication-options → WebAuthn auth options
├── auth-verify-passkey         → Verify passkey
├── send-push         → Web Push VAPID + AES-128-GCM (RFC 8291)
├── pattern-detect    → Claude behavioral patterns → behavioral_patterns
├── daily-brief       → Claude daily brief → daily_briefs (cached/day)
├── memory-manager    → CRUD personal_memory (JWT auth)
├── data-export       → PDPA export all data as JSON (JWT auth)
├── account-delete    → PDPA delete account + all data (JWT + confirmToken)
├── auth-rate-limit   → Rate limit check/increment/reset
└── account-recovery  → Passkey recovery via magic link
```
