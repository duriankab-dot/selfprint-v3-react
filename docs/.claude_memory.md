### สิ่งที่มีจริงในโค้ด (ไกลกว่าที่ docs เก่าบอก)
- **Onboarding 7 ขั้นตอน:** Emotion → NovaConversation (birth data) → AICreationSequence → InitialBlueprint (60%) → FinetuningQuestions (4 คำถาม) → FullAnalysis (85%+) → Home
- **Dashboard:** เชื่อม Supabase จริง (`src/services/supabase-service.ts`) — insights, decision log table, autonomy trend, filter, export
- **Chat:** `ChatPage.tsx` เต็มรูปแบบ + `TwinContext`/`twinStore.ts` (Zustand — conversation memory, autonomy score, pattern tracking, feedback)
- **Backend:** `server/handler/chat.js` (Brain Gateway, รับ system prompt) + `api/nova.ts`, `api/autonomy-log.ts` (Vercel functions)
- **selfprintChat.ts** (`src/lib/api/selfprintChat.ts`) — wrapper เรียก Brain Gateway, ใช้จริงใน `nova-ai.ts` และ `useChat.ts`
- **.env มีครบ:** Supabase, Firebase, Anthropic API key

### Hub/Mood system
- 12 hubs (ใน `HubContext.tsx`: identity, decision, relationship, career, health, money, ai-twin, learning, creativity, spirituality, impact, **activities** — สังเกตชื่อ `activities` ไม่ใช่ `activity`)
- 6 moods (ใน `EmotionContext.tsx`): stressed, confused, confident, drained, ready, reflective
- Mood/Hub sync ไป DOM ผ่าน `document.documentElement.setAttribute('data-mood'/'data-hub', ...)` — component ไม่จำเป็นต้อง destructure `mood`/`hub` เองถ้าแค่ใช้ CSS var
