### §46 — Advanced Adaptive Environments ✅ (NEW)

**Files created:**

#### `src/lib/experience/TimeOfDayEngine.ts`
- 4 ช่วงเวลา: Morning (05-11) / Afternoon (12-16) / Evening (17-20) / Night (21-04)
- Output per period: energyLevel, audioCharacter, cssVars (--tod-*), labelThai, emoji, descriptionThai
- CSS vars: `--tod-period`, `--tod-bg-tint`, `--tod-glow-intensity`, `--tod-particle-speed`, `--tod-transition-speed`, `--tod-energy`, `--tod-label`
- `applyToDocument()` ช่วย inject vars + `data-tod` attribute
- `minutesToNextPeriod()` คำนวณเวลาถึง transition ถัดไป

#### `src/lib/experience/SoundscapeEngine.ts`
- 24 curated soundscapes ครอบคลุม mood × hub × period combinations
- `recommend(hub, mood, period)` — 4-pass matching algorithm:
  1. hub + mood + period ตรงทั้งหมด
  2. hub + mood (any period)
  3. mood + period (any hub)
  4. mood only (universal)
  5. fallback: 'ambient-minimal'
- แต่ละ soundscape มี: `musicExperience` (maps to AudioContext), `audioCharacter`, `audioStyle`, `labelThai`, `descriptionThai`

#### `src/lib/experience/EnvironmentEngine.ts`
- Orchestrates TimeOfDayEngine + SoundscapeEngine → EnvironmentConfig
- `shouldTransition: true` เมื่อ period เปลี่ยนจากรอบก่อน
- รวม CSS vars: `--tod-*` + `--env-soundscape-id`, `--env-audio-character`, `--env-transition-duration`, `--env-energy-level`
- `ambientDescription` string สำหรับ UI (เช่น "🌅 ยามเช้า — โฟกัสยามเช้า")

#### `src/context/EnvironmentContext.tsx`
- Tick ทุก 60 วินาที ตรวจ period transition
- Inject CSS vars → `:root` ทุกครั้งที่ environment เปลี่ยน
- Set `data-tod` attribute บน `<html>` (สำหรับ CSS selectors)
- Sync `AudioContext.setExperience()` เมื่อ period เปลี่ยน — **เฉพาะถ้า musicEnabled = true** (§19 User Preference rule)
- `isTransitioning` flag (800ms) สำหรับ animation ใน components
- `refresh()` สำหรับ force recompute
- `useEnvironment()` hook

#### Integration:
- `src/lib/experience/index.ts` → export TimeOfDayEngine, SoundscapeEngine, EnvironmentEngine
- `src/App.tsx` → `<EnvironmentProvider>` ครอบ `<EvolutionProvider>` (inside AudioProvider)
