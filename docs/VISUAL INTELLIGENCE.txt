48. FINAL DIRECTIVE TO DEVELOPMENT TEAM

DO NOT REBUILD SELFPRINT.

DO NOT CREATE A NEW TWIN SYSTEM.

DO NOT CREATE A NEW WORLD SYSTEM.

DO NOT CREATE LARGE STATIC VISUAL ASSET LIBRARIES.

DO NOT USE FULL 3D AS THE DEFAULT SOLUTION.

DO NOT GENERATE NEW IMAGES AT RUNTIME FOR NORMAL USER NAVIGATION.

Build a Procedural-first, Asset-minimal, AI-driven 2D/2.5D Visual Intelligence Engine integrated with the existing SELFPRINT V5 architecture.

Preserve the existing functional Landing → Quick Analysis → Tuning → Full Analysis → Twin Generation flow.

Implement Smart Entry for New Users, Returning Users and PWA.

Returning Users with an existing Twin should enter through their Twin.

Keep Twin Identity persistent across all Worlds.

Use World State as the shared source of truth for both Visual Engine and AI Context.

Make Thai and English first-class experiences across the complete lifecycle.

Use AI to determine Visual State and Visual Parameters, while Code deterministically renders the experience.

Generate parameters, not pictures.

Audit first. Reuse second. Integrate third. Upgrade fourth. Create new only when a verified production gap exists.

Production verification is mandatory.
