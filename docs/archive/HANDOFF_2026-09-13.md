## ❌ ปัญหาที่ยังไม่แก้ (ต้องทำใน session หน้า)

### 1. Migration 021_world_preferences.sql — Index name conflict

**Error:** `relation "idx_world_preferences_user_id" already exists`

**สาเหตุ:** 
- Migration 021 สร้าง `idx_world_preferences_user_id` index
- แต่ index นี้มีอยู่แล้วจาก migration อื่น (อาจเป็น 031_world_stats_fixes.sql หรือ run ซ้ำ)
- แม้จะใช้ `DROP INDEX IF EXISTS` + `CREATE INDEX IF NOT EXISTS` แล้ว ก็ยัง error

**วิธีแก้ (ต้องลอง):**
```sql
-- ใน SQL Editor:
DROP INDEX IF EXISTS idx_world_preferences_user_id;
CREATE INDEX idx_world_preferences_user_id ON public.world_preferences(user_id);
```

**หรือ** เปลี่ยนชื่อ index เป็น `idx_world_preferences_uid` แล้ว update ทุกที่ที่ใช้

**สถานะ:** แก้ 10+ รอบยังไม่ผ่าน — ต้องลองวิธีอื่น
