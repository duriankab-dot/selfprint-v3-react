## Section 1: Decision Fatigue คืออะไร

### Science: Ego Depletion Theory (Baumeister, 1998)

```
Mental energy (Willpower) = Limited resource
Each decision = burns energy
Afternoon 3pm = low battery → bad decisions

Example:
- Morning: "Should hire X or Y?" → thoughtful choice
- Evening: "What to eat?" → just grab candy (impulsive)
```

### Real Impact:

```
Judge study: Likelihood of parole approval:
- Morning (fresh): 65% approval
- Afternoon (tired): 10% approval
→ Same case, same judge, different time = different outcome
```

## Section 2: 3 Types of Decision Fatigue

### Type 1: Analytical Overload

```
Too much information → can't process
Symptom: Overthinking "should I switch jobs?"
Solution: Filter inputs (ask AI first)
```

### Type 2: Willpower Depletion

```
Too many choices → mental energy runs out
Symptom: Evening decisions = poor quality
Solution: Make important decisions early
```

### Type 3: Responsibility Burden

```
High stakes → anxiety + hesitation
Symptom: Procrastinate on big calls
Solution: Use AI Twin to reduce stakes (simulate first)
```
