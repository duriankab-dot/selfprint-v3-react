## เมื่อวิกฤต: ตัวจริงของคุณออกมา

**สมชาย (Pilot)** ได้รับการฝึกหลากหลาย:
- Normal flight ← ทำได้ดี
- Emergency drill ← ทำได้ดี
- **Real emergency (engine failure) ← panic, ลืมขั้นตอน** → crash

**ปลายทาง (CEO)**:
- Normal meeting ← ชาร์จชาร์จ เปิดผลลัพธ์ดี
- Budget cut crisis ← Decision ผิด, delay ตัดสิน
- **Lawsuit ล้ม contract ← frozen, ไม่รู้ว่าจะ do what** → lose $10M

---

## ตัวจริง: Stress Response ≠ Normal Response

### Normal Mode
- คิดชัด
- ตัดสินใจเร็ว
- เรียกใหญ่มาปรึกษา

### Stress/Crisis Mode
- Amygdala "ตั้ก" → หา decision ด้วย "Survival instinct"
- ไม่มีเวลา "คิด" อย่างที่คิดในสำนักงาน
- ปฏิกิริยาจริง = "Freeze / Fight / Flight"

---

## Stress Response Pattern คืออะไร

**ไม่ใช่ "character"** แต่เป็น "hardwired pattern"

เมื่อเครียด/วิกฤต คุณมี **default coping style** ที่เหมือนเดิมเสมอ:

### 1. Fighter Type
- **Pattern:** Attack ปัญหา / ทะเลาะ / Aggressive ขึ้น
- **ตัวอย่าง:** ลูกค้าเสียหาย → ทะเลาะ / ตัดสิน ด้วย anger
- **ผล:** บางที Decisive ดี บางที reckless

### 2. Freezer Type
- **Pattern:** Paralysis / ไม่รู้ว่าทำไร / Overthink
- **ตัวอย่าง:** ลูกค้าเสียหาย → ไม่พูด / ไม่ decide ทันที
- **ผล:** แก้ไขช้า ส่วนนั้น ทำให้พัง worse

### 3. Flight Type
- **Pattern:** ทำให้ลดเบา / escape / ปกปิด
- **ตัวอย่าง:** ลูกค้าเสียหาย → hint ว่า "ไม่ได้รู้" / "ยุ่งเรื่องอื่น"
- **ผล:** Trust หายไป

### 4. Adapter Type
- **Pattern:** ปรับตัว / Seek support / Collaborate ขึ้น
- **ตัวอย่าง:** ลูกค้าเสียหาย → เรียกทีม / ชอบปรึกษา / Calm + strategic
- **ผล:** ดีที่สุด แต่หนัก

## 12 มิติ → Stress Response Type

ไม่ใช่ "character" แต่เป็น "combination ของ dimensions"

### ตัวอย่างการคำนวณ

**Executor + High Independence + Low Empathy = Fighter Type ที่อาจ aggressive**
- ตอน normal ← ดี
- ตอน crisis ← อาจ reckless หรือ hurt คน

**Support + High Collaboration + Anxious = Freezer Type ที่อาจ lethargic**
- ตอน normal ← ดี
- ตอน crisis ← อาจ ไม่ decide ทันเวลา

## ตัวอย่าง: Crisis Pattern ที่ต่างกัน

### Case #1: CEO (Fighter Type)

**Normal:** Decisive, results-driven, independent ← ดี

**Crisis (Startup board room — funding pulled):**
- ตัดสินใจแบบ aggressive ← อาจ reckless
- บอก ทีม "layoff 50%"  tomorrow ← แทนที่จะ consult
- Partner เห็น "harsh" ← ความไว้วางใจหาย

**ผล:** Survive สั้นพระ แต่ damages เยอะ

### Case #2: HR Director (Freezer Type)

**Normal:** Thoughtful, collaborative, empathetic ← ดี

**Crisis (Discrimination lawsuit):**
- ไม่ call lawyer ทันที ← frozen
- ไม่ inform board ← ปกปิด (ไม่ได้ตั้งใจ)
- "ต้องคิด best solution" ← แล้ว 2 เดือน มันเป็นข่าว
- Damage control ยากขึ้นจัก

**ผล:** Company ความเสียหายใหญ่กว่าถ้า early action

## วิธี "Train" Crisis Decision Making

ไม่ใช่ "change personality" แต่ "override default pattern"

### วิธี 1: Create Decision Framework ตอน Normal

ตอนไม่เครียด:
- "ถ้า Crisis [X] เกิด ขั้นตอนอะไร?"
- "Call ใคร ก่อน?"
- "ตัดสินใจโดยใช้ [Y criteria] ไม่ใช่ emotion"

**ตัวอย่าง:**
- "ถ้า Lawsuit: ทันที call lawyer + CEO + CFO"
- "ไม่ต้อง consult หมด ก่อน action"

- ต้อง decide ใน 1 ชั่วโมง
- ดู: ตัวเอง freeze? fight? collaborate?

## ตัวอย่าง: From Freezer → Adapter (Training)

**Original Pattern:** Freezer (paralysis during crisis)

**Training Process:**
1. **Month 1:** ทำ Crisis Simulation ให้เห็นว่า "ตัวเอง Freeze"
2. **Month 2:** Create "Emergency Decision Checklist" (ตอน Normal)
   - "Lawsuit ← Call lawyer within 1 hour"
   - "Financial crisis ← Brief board within 2 hours"
3. **Month 3:** Role-play ครั้งละ 30 นาที
   - ทำ Crisis Scenario
   - ใช้ Checklist แทน ใช้ Intuition
   - ทำให้ "fast decision" เป็น habit
4. **Month 4:** ลอง real decision (ย่อย) ด้วย Checklist

**ผล:** Freezer pattern ลดลง Adapter pattern เพิ่มขึ้น

## Crisis Decision Framework

### วิธี Decide ตอนวิกฤต ใน 10 นาที

**Step 1 (1 min): Acknowledge**
- "OK วิกฤต เกิดแล้ว"
- ลืม emotion ก่อน

**Step 2 (2 min): Information Gathering**
- "ข้อมูล critical มีไหม?"
- ไม่ต้อง info perfect

**Step 3 (3 min): Decision Framework**
- "ตามแผนแล้ว step ไหน?"
- ใช้ Checklist ที่เตรียมไว้

**Step 4 (3 min): Decide + Communicate**
- "Action นี่นั่น"
- Tell team / Stakeholder ทันที

**Step 5 (1 min): Reflection**
- "Correct? Adjust ได้ไหม?"
