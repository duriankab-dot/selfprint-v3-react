## Section 2: The 12 Engines Breakdown

### Engine 1: Leadership Assessment Engine

```
Input: 5 questions about decision-making, team dynamics, comfort with authority
Output: Leadership score (1-10)
Logic: 
├─ High decision comfort + high confidence = natural leader
├─ Low decision comfort + high delegation = collaborative type
└─ Medium = situational leader
```

### Engine 2: Risk Appetite Engine

```
Input: Questions about comfort with uncertainty, financial risk, change
Output: Risk appetite score (1-10)
Logic: Detect genuine risk tolerance (not bravado)
├─ Consistency check: Actions vs claims
└─ Output: "You're 7/10 risk, but act 4/10" → Blind spot detected
```

### Engines 3-12: Similar Pattern

```
Each Engine:
├─ Takes 4-5 relevant questions
├─ Cross-validates with other engines
├─ Detects inconsistencies (= blind spots)
├─ Scores 1-10
└─ Contributes to holistic profile
```

```

Conversation:
├─ Engine 1→7: "Your fast decisions + leadership = works?"
├─ Engine 7→6: "Your speed + coldness = people feel rushed"
├─ Engine 6→1: "Your ambition + emotional distance = lonely at top"

Collective insight:
"You're a natural leader BUT blind spot: relationships suffer due to speed + cold tone"
```

### Contradiction Detection:

```
If you answer:
- "I listen well" (emotional engine)
- AND "I prefer quick decisions" (speed engine)
- AND "People say I interrupt" (social engine)

Engines cross-reference:
→ "These contradict. Blind spot: You think you listen but data says no."
```
