### P-1 · ANALYSIS-PERSIST-001 (Critical — ส่งผลกระทบ TWIN-MEMORY-001 โดยตรง)

**ปัญหา:** `analysisStore.currentAnalysis` ไม่ persist — ถ้า user reload หน้า TwinChat  
`strengths / blindSpots / selfOverview` จะเป็น `[]` ทั้งหมด → Twin ฉลาดแค่ใน session แรก  

**Root cause:** Zustand store ไม่มี `persist` middleware + ไม่ fetch จาก DB เมื่อ store ว่าง

**Fix plan:**
```typescript
// TwinChat.tsx — useEffect on mount, run once
useEffect(() => {
  if (currentAnalysis || !session?.user?.id || !supabase) return;
  // fetch latest blueprint from profiles_blueprints
  supabase
    .from('profiles_blueprints')
    .select('sice_results, final_analysis')
    .eq('user_id', session.user.id)
    .order('created_at', { ascending: false })
    .limit(1)
    .single()
    .then(({ data }) => {
      if (data?.final_analysis) {
        setCurrentAnalysis(data.final_analysis as FullAnalysisOutput);
      }
    });
}, [session?.user?.id]);
```

**Files:** `src/pages/TwinChat.tsx` + import `setCurrentAnalysis` from analysisStore  
**Acceptance:** reload TwinChat → strengths/blindSpots ยังอยู่ใน twinProfile JSON

## 📋 ARCHITECTURE QUICK REF (อัปเดตล่าสุด)

### Twin vs Nova (สรุปชัด)

| | Twin | Nova |
|--|------|------|
| Model | claude-3-5-sonnet-20241022 | claude-3-5-haiku-20241022 |
| Temp | 0.8 | 0.7 |
| max_tokens | 1500 | 1000 |
| Rate | 40/min | 60/min |
| System | Required (400 if missing) | Optional (has default) |
| Personality | Seer-Scientist Hybrid | Socratic Guide |
| Knows user? | ✅ Full profile JSON | ❌ Universal, no profile |
| Env override | TWIN_MODEL_ID | NOVA_MODEL_ID |
| Function | api/twin.ts | api/nova.ts |

### Stores (Zustand)
- `useUserStore` → `profile.birthDate/birthTime/birthPlace`
- `useAnalysisStore` → `currentAnalysis: FullAnalysisOutput | null` **(⚠️ not persistent — see P-1)**
- `useTwin` (Context) → `twin.primaryArchetype, secondaryArchetype, maturityScore`

### Key Rules (ห้ามลืม)
```
CSS:      var(--...) เท่านั้น — ห้าม hardcode
userId:   useAuth().session?.user?.id เท่านั้น
import:   verbatimModuleSyntax → import type {} for type-only
supabase: import { supabase } from '../services/supabase-service'
supabase: ต้องมี guard: if (!supabase) return
Hooks:    ประกาศก่อน early return เสมอ (Rules of Hooks)
DB:       ไม่รัน migration เอง — ให้ SQL สำหรับ user รันเอง
Git:      ไม่รัน git command เอง — ให้ Windows command สำหรับ user
```
